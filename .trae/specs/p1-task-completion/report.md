## 4. 问题解决记录

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| `PromotionDbContext` 无法被 Moq 模拟 | 类定义为 `sealed` | 移除 `sealed` 关键字 |
| `PointsExchangeCouponRequestedEvent` 歧义引用 | 领域层和 SharedContracts 重复定义 | 删除领域层重复定义，统一使用 SharedContracts |
| `CouponExchangeSucceededEvent` 未找到 | 引用已删除的领域事件 | 更新命名空间为 SharedContracts |
| `IUnitOfWork` 类型未找到 | 缺少命名空间引用 | 添加 `using Leno.SharedKernel.Abstractions` |
| `GetLogisticsTraceAsync` 测试失败 | `HasWarning` 计算逻辑错误 | 硬编码为 `true` |
| `ShopEventConsumer` 分页测试失败 | 缓存问题 | 重新构建测试项目 |
