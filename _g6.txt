##### deploy/scripts/seed-consul-kv.ps1
1: ﻿<#
2: .SYNOPSIS
3:   将 deploy/consul/kv-seed.json 清单中的配置键批量写入 Consul KV（P0-D）。
4: 
5: .DESCRIPTION
6:   生产配置主通道为 Consul KV：所有 BC 的 Program.cs 调用 AddLenoConsulConfig()
7:   （Winton Consul 源位于配置链尾，KV 优先级高于 env 兜底与 appsettings.json）。
8:   本脚本读取 deploy/consul/kv-seed.json（键名 = 配置键，':' → '__'，与代码读取键
9:   严格一致，见 deploy/docs/consul-kv-coverage-audit.md），解析 value 中的
10:   ${ENV_VAR} 占位符后通过 Consul HTTP API（PUT /v1/kv/{key}）写入。
11: 
12:   安全约束：
13:   - 清单与脚本中禁止出现真实密码，敏感值一律使用 ${ENV_VAR} 占位符引用环境变量；
14:   - 环境变量缺失时默认报错拒绝写入（不写入未解析的占位符文本）；
15:   - 非 sensitive 项可声明 default 作为环境变量缺失时的兜底默认值。
16: 
17: .PARAMETER ConsulAddress
18:   Consul HTTP 地址。默认取环境变量 LENO_CONSUL_URL，否则 http://localhost:8500。
19: 
20: .PARAMETER ConsulToken
21:   Consul ACL Token（可选，启用 ACL 的集群必填）。
22: 
23: .PARAMETER ManifestPath
24:   KV 种子清单路径，默认 deploy/consul/kv-seed.json（相对仓库根）。
25: 
26: .PARAMETER DryRun
27:   只打印将执行的写入动作（含值是否解析成功），不实际请求 Consul。
28: 
29: .EXAMPLE
30:   # 干跑：核对将要写入的键值
31:   ./seed-consul-kv.ps1 -DryRun
32: 
33: .EXAMPLE
34:   # 正式写入（敏感值先注入环境变量）
35:   $env:LENO_DB_ORDER = "Server=sqlserver,1433;Database=LenoOrder;..."
36:   $env:LENO_RABBITMQ_PASSWORD = "..."
37:   ./seed-consul-kv.ps1 -ConsulAddress "http://consul:8500"
38: #>
