# 积分统计 - 系统管理后台

## 1. 页面定位
- **所属端**：系统管理后台
- **所属模块**：01-dashboard 仪表盘
- **页面类型**：看板页
- **目标用户**：系统管理员（Admin）
- **核心目标**：查看积分发放量、消耗量与净增趋势，监控积分通胀与活动异常。
- **访问入口**：Sider「仪表盘 → 积分统计」/ 运营总览 KPI 跳转
- **实现状态**：✅ 已实现

## 2. 页面布局与信息架构
- **整体布局**：顶部时间筛选 + 3 KPI 卡片 + 发放/消耗双系列趋势 + 来源分布饼图。
- **关键区域**：
  - 区域 A（筛选条）：`DateTimeRangePicker`，默认近 30 天（积分统计周期较长）。
  - 区域 B（KPI 行）：3 个 `DashboardCard` — 发放量、消耗量、净增（发放−消耗），均以积分为单位。
  - 区域 C（主趋势）：`ChartLine` 双系列（发放/消耗）按日趋势，高度 320px，含净增副系列虚线。
  - 区域 D（来源分布）：`ChartPie` 发放来源（订单完成/签到/任务/活动赠送），环形。
- **响应式断点**：≥1200px C/D 双列；992-1199px 单列。
- **首屏内容**：3 KPI 数值 + 双系列趋势曲线。
- **线框图描述**：

```
┌────────────────────────────────────────────────┐
│ [时间范围 ▼ 近30天] [刷新]                      │
├──────────┬──────────┬──────────────────────────┤
│ 发放量    │ 消耗量    │     净增                 │
│ 1.2M     │ 0.8M     │     +0.4M                │
│ ↑8.2%    │ ↑5.1%    │     ↑12.3%               │
├──────────┴──────────┴──────────────────────────┤
│      发放 vs 消耗 双系列趋势（含净增虚线）       │
├────────────────────────────────────────────────┤
│           发放来源分布（环形饼图）               │
└────────────────────────────────────────────────┘
```

## 3. 数据模型与 API 对接
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| GET | `/api/admin/dashboard/points-stats` | 查询积分发放量统计 | Admin,Operator |

- **请求参数**：`start`、`end`（ISO 8601）；返回 `DashboardReportDto`，`ReportType=PointsIssued`。
- **响应字段**：`Metrics` 中 `Key` 含 `issued`/`consumed`/`net`/`dailyTrend:[{date,issued,consumed}]`/`sourceDistribution:[{source,value}]`。
- **数据加载策略**：进入页面立即加载；30 天趋势数据点约 30 个，前端不再降采样。
- **缓存策略**：缓存 10 分钟（积分统计非实时），键 `points-stats:{start}:{end}`。

## 4. 交互流程
- **主流程**：
  1. 进入页面 → GET `/api/admin/dashboard/points-stats?start=...&end=...` → KPI + 趋势 + 饼图同步渲染。
  2. 切换时间范围 → 重新请求 → 全部刷新。
  3. 悬浮趋势线节点 → `<a-tooltip>` 显示当日发放/消耗/净增明细。
- **分支流程**：
  - 净增为负：KPI 数值显示危险色 `#FF4D4F`，附 `Tooltip`「消耗超过发放，请检查营销活动配置」。
  - 单日发放量突增（>均值 3 倍）：趋势线该节点高亮主色，悬浮提示「异常峰值」。
- **跨页面流转**：点击「发放来源」某项 → 跳 `/audit/audit-logs?resourceType=Points&keyword={source}` 查看相关审计。
- **状态机可视化**：无状态字段。

## 5. 组件清单
- **基础组件**：`<a-card>`、`<a-tooltip>`、`<a-segmented>`
- **业务组件**：
  - `DashboardCard`（见 shared/components.md §8）
  - `DateTimeRangePicker`（见 shared/components.md §4）
  - `EmptyState`（见 shared/components.md §5）
- **图表组件**：`ChartLine`（见 shared/components.md §7.1）、`ChartPie`（见 shared/components.md §7.2）
- **图标使用**：`ArrowUpOutlined`/`ArrowDownOutlined` 趋势箭头。
- **空状态**：「暂无积分数据」+ 刷新按钮。

## 6. 视觉规范
- **主色应用**：发放系列 `#1677FF`；消耗系列 `#FAAD14`；净增虚线 `#52C41A` 或 `#FF4D4F`（按正负）。
- **状态色**：净增正值绿、负值红；异常峰值主色高亮。
- **间距**：KPI 间距 24px；图表间距 32px。
- **字体**：KPI 数值 24px semibold；趋势轴 12px；图例 14px。
- **图标尺寸**：趋势箭头 16px。

## 7. 异常处理与边界
- **加载态**：KPI 与图表均使用 `<a-skeleton :active="true" />`。
- **空数据**：`EmptyState` 兜底。
- **错误态**：网络错误 `message.error` 3s。
- **权限控制**：页面级 `roles: ['Admin','Operator']`。
- **并发与乐观锁**：只读无锁。
- **危险操作确认**：无危险操作。

- [ ] 双系列趋势图例可点击切换显隐
- [ ] 净增为负时数值与虚线染红
- [ ] 异常峰值节点高亮可识别
- [ ] 30 天趋势渲染流畅不卡顿
- **性能要求**：首屏 < 1.5s；折线 30 点开启 `large: false`（数据量小不启用）。
- **可访问性**：图表 `aria-label`；数值含「积分」单位；色盲友好。
