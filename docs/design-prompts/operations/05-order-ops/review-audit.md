# 评价审核 - 运营管理后台

## 1. 页面定位
- **所属端**：运营管理后台
- **所属模块**：05-order-ops 订单运营
- **页面类型**：列表审核页（评价审核与违规隐藏）
- **目标用户**：运营管理员（Operator）
- **核心目标**：分页查询全平台商品评价，审核通过合规评价，隐藏违规评价（含垃圾广告/辱骂/虚假），维护评价体系健康。
- **访问入口**：左侧菜单「订单运营 → 评价审核」；待办工作台「待审核评价」徽标跳转。
- **实现状态**：✅ 已实现

## 2. 页面布局与信息架构
- **整体布局**：顶部筛选条 + 操作工具栏 + 评价列表表格 + 评价详情抽屉（含图片与回复）+ 隐藏对话框。
- **关键区域**：
  - 区域 A（筛选条）：`<a-form inline>` 含商品名称关键词、评价状态（待审核/已通过/已隐藏）、评分（1-5）、时间范围、查询/重置
  - 区域 B（工具栏）：批量通过、批量隐藏、刷新、导出
  - 区域 C（评价表格）：`<a-table>` 列含评价内容摘要、商品、买家、评分、图片数、卖家回复、状态、评价时间、操作列
  - 区域 D（详情抽屉）：`<a-drawer width="640">` 展示评价全文、图片轮播、评分、买家信息、商品信息、卖家回复、审核历史
  - 区域 E（隐藏对话框）：`<a-modal>` 含隐藏原因分类（垃圾广告/辱骂/虚假/其他）、详细原因（必填）
- **响应式断点**：≥1200px 抽屉 640px；992-1199px 抽屉 480px。
- **首屏内容**：筛选条 + 待审核状态的评价列表前 20 条。
- **线框图描述**：

## 3. 数据模型与 API 对接
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| GET | `/api/admin/reviews` | 分页查询评价（按状态过滤） | Operator, Admin |
| POST | `/api/admin/reviews/{id}/approve` | 审核通过评价 | Operator, Admin |
| POST | `/api/admin/reviews/{id}/hide` | 隐藏违规评价 | Operator, Admin |

- **请求参数**：查询参数 `status`（ReviewStatus?）、`page`、`pageSize`；隐藏请求体 `ModerateReviewDto` 含 `Reason`（必填）。
- **响应字段**：`ReviewListResultDto`，含 `Items`（每项含 `Id`、`Content`、`Rating`、`ImageUrls`、`ProductId`、`ProductName`、`UserId`、`SellerReply`、`Status`（Pending/Approved/Hidden）、`CreatedAt`）、`Total`。
- **数据加载策略**：进入页面加载待审核评价；切换状态重新请求；审核后局部更新状态列。
- **缓存策略**：不缓存，评价状态实时性强。

## 4. 交互流程
- **主流程**：
  1. 进入页面 → 加载待审核评价 → 渲染表格
  2. 点击「详情」→ 打开抽屉展示评价全文、图片、卖家回复
  3. 点击「通过」→ `<ConfirmDialog>` 确认 → 调用 approve → 评价对买家端可见
  4. 点击「隐藏」→ 弹出对话框 → 选择原因分类 + 填写详细原因 → 调用 hide → 评价对买家端隐藏
- **分支流程**：
  - 批量审核：勾选多行 → 批量通过/隐藏 → 串行调用 → 汇总结果
  - 含图片评价：详情抽屉展示图片轮播，可放大预览
  - 已隐藏评价：买家端不可见，仅运营可查看
- **跨页面流转**：点击「商品」跳转商品审核页（携带商品筛选）；点击「买家」跳转用户管理。
- **状态机可视化**：Pending（待审核）→ Approved（已通过）/ Hidden（已隐藏）。隐藏可逆，运营可重新通过。

## 6. 视觉规范
- **主色应用**：通过按钮主色 `#1677FF`，隐藏按钮默认色。
- **状态色**：待审核 `#FAAD14` 橙、已通过 `#52C41A` 绿、已隐藏 `#8C8C8C` 灰。
- **评分色**：星星 `#FAAD14` 金，低分（1-2）行背景 `#FFF1F0` 提示。
- **间距**：筛选条与表格 16px，表格行高 56px（含图片缩略图），抽屉区块 24px。
- **字体**：评价内容 14px `#000000D9`，商品名 14px medium，时间 12px `#8C8C8C`。
- **图片缩略图**：48×48px 圆角 4px，多图显示数量角标。

## 7. 异常处理与边界
- **加载态**：表格 `<a-spin>` 包裹；抽屉加载 Skeleton。
- **空数据**：列表空显示「暂无评价」，按状态筛选提示「该状态下暂无评价」。
- **错误态**：审核失败 `message.error('审核操作失败，请重试')`；并发冲突提示「评价状态已变更，请刷新」。
- **权限控制**：Operator/Admin 可访问；审核操作需 `review:audit` 权限。
- **并发与乐观锁**：审核基于聚合版本校验，冲突提示刷新。
- **危险操作确认**：隐藏为危险操作，强制 `<ConfirmDialog>`，说明评价将对买家端不可见；批量操作需确认影响条数。
