# 支付渠道配置 - 运营管理后台

## 1. 页面定位
- **所属端**：运营管理后台
- **所属模块**：06-payment-ops 支付运营
- **页面类型**：配置管理页（渠道配置 CRUD + 启停 + 测试）
- **目标用户**：运营管理员（Operator）
- **核心目标**：维护各支付渠道（微信/支付宝/其他）的配置项（AppId/密钥/回调地址等），支持启停与配置更新，保障支付渠道可用性。
- **访问入口**：左侧菜单「支付运营 → 支付渠道配置」；支付记录页渠道列跳转。
- **实现状态**：✅ 已实现

## 2. 页面布局与信息架构
- **整体布局**：左侧渠道列表 + 右侧配置详情/编辑面板。
- **关键区域**：
  - 区域 A（渠道列表）：左侧 280px 宽，列出全部支付渠道卡片（微信/支付宝/其他），每卡片含渠道图标、名称、状态点、配置项数
  - 区域 B（详情面板）：右侧展示选中渠道的配置项列表（脱敏显示敏感字段）、状态、最后更新人与时间
  - 区域 C（编辑表单）：右侧切换为编辑模式，含各配置项输入（敏感字段脱敏显示但可更新）、状态开关
  - 区域 D（测试发送）：编辑面板底部「测试连接」按钮，验证配置是否正确
- **响应式断点**：≥1200px 左右分栏；992-1199px 渠道列表折叠为下拉选择。
- **首屏内容**：渠道列表 + 默认选中微信渠道的配置详情。

## 3. 数据模型与 API 对接
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| GET | `/api/admin/payment-channels` | 获取所有渠道配置项列表 | Admin, Operator |
| GET | `/api/admin/payment-channels/{id}` | 获取单个配置项详情 | Admin, Operator |
| PUT | `/api/admin/payment-channels/{id}` | 更新配置项值 | Admin, Operator |
| POST | `/api/admin/payment-channels/{id}/enable` | 启用配置项 | Admin, Operator |
| POST | `/api/admin/payment-channels/{id}/disable` | 禁用配置项 | Admin, Operator |

- **请求参数**：`UpdatePaymentChannelConfigDto` 含 `ConfigValue`（敏感字段脱敏显示但提交时传明文）、`Description`。
- **响应字段**：`List<PaymentChannelConfigDto>`，每项含 `Id`、`Channel`（WeChatPay/Alipay/Other）、`ConfigKey`、`ConfigValue`（脱敏）、`IsSensitive`、`Status`（Active/Inactive）、`UpdatedBy`、`UpdatedAt`、`Description`。
- **数据加载策略**：进入页面加载全部渠道配置；选中渠道过滤展示；编辑提交后局部更新配置项。
- **缓存策略**：不缓存，配置变更需实时生效。

## 4. 交互流程
- **主流程**：
  1. 进入页面 → 加载全部渠道配置 → 渠道列表渲染 → 默认选中微信渠道
  2. 点击渠道卡片 → 右侧展示该渠道配置项详情（敏感字段脱敏）
  3. 点击「编辑」→ 切换为编辑模式 → 修改配置项 → `<IdempotencyButton>` 提交 → 局部刷新
  4. 点击「测试连接」→ 调用测试发送 → 返回连接结果（成功/失败 + 错误信息）
  5. 点击「停用」→ `<ConfirmDialog>` 确认 → 调用 disable → 渠道状态变更为禁用
- **分支流程**：
  - 敏感字段编辑：脱敏显示 `****`，点击编辑后清空可重新输入，留空表示不修改
  - 测试连接失败：展示具体错误信息（如签名错误/网络超时）
  - 停用主渠道：提示「停用后该渠道支付将不可用，确认无进行中支付」
- **跨页面流转**：点击「测试连接」成功后可跳转支付记录页查看该渠道记录。
- **状态机可视化**：渠道配置状态 Inactive ↔ Active（启用/禁用双向切换）。

## 6. 视觉规范
- **主色应用**：编辑/测试按钮主色 `#1677FF`，停用按钮默认色。
- **状态色**：启用 `#52C41A` 绿点、禁用 `#8C8C8C` 灰点（渠道列表卡片左侧 6px 圆点）。
- **敏感字段**：脱敏显示 `****` 灰色 `#8C8C8C`，编辑时清空为可输入。
- **间距**：渠道列表项间距 8px，详情面板区块 24px，配置项行高 48px。
- **字体**：渠道名称 14px medium，配置键 14px mono，配置值 14px `#000000D9`，脱敏值 `#8C8C8C`，更新时间 12px `#8C8C8C`。
- **图标尺寸**：操作按钮图标 16px，渠道图标 24px。

## 7. 异常处理与边界
- **加载态**：渠道列表与详情面板 `<a-spin>` 包裹。
- **空数据**：渠道列表空显示「暂无支付渠道配置」。
- **错误态**：测试连接失败展示错误信息；更新失败 `message.error('配置更新失败，请重试')`。
- **权限控制**：Operator/Admin 可访问；编辑/启停需 `payment:config` 权限。
- **并发与乐观锁**：编辑提交基于聚合版本校验，冲突提示「配置已被他人修改，请刷新」。
- **危险操作确认**：停用渠道为危险操作，强制 `<ConfirmDialog>`，说明该渠道支付不可用。
- **安全边界**：敏感字段传输加密（HTTPS），脱敏展示防止泄露，更新操作记录审计日志。
