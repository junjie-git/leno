# 退款记录 - 运营管理后台

## 1. 页面定位
- **所属端**：运营管理后台
- **所属模块**：06-payment-ops 支付运营
- **页面类型**：列表查询页（全平台退款记录）
- **目标用户**：运营管理员（Operator）
- **核心目标**：分页查询全平台退款记录，按订单/状态过滤，监控退款成功率与渠道回写状态，定位退款异常。
- **访问入口**：左侧菜单「支付运营 → 退款记录」；支付统计页失败笔数跳转；支付记录页退款链接跳转。
- **实现状态**：✅ 已实现

## 2. 页面布局与信息架构
- **整体布局**：顶部筛选条 + 操作工具栏 + 退款记录表格 + 退款详情抽屉（含关联售后与渠道回写）。
- **关键区域**：
  - 区域 A（筛选条）：`<a-form inline>` 含退款单号、订单号、退款状态（待退款/已退款/退款失败）、时间范围、查询/重置
  - 区域 B（工具栏）：导出列表、刷新、统计概览（各状态计数与成功率）
  - 区域 C（退款表格）：`<a-table>` 列含退款单号、订单号、买家、退款金额、退款渠道、状态、关联售后单、申请时间、退款完成时间、操作列
  - 区域 D（详情抽屉）：`<a-drawer width="640">` 展示退款基础信息、关联售后单、渠道回写记录、状态变更时间线
- **响应式断点**：≥1200px 抽屉 640px；992-1199px 抽屉 480px。
- **首屏内容**：筛选条 + 全状态退款记录近7天前 20 条。
- **线框图描述**：

## 3. 数据模型与 API 对接
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| GET | `/api/admin/refunds` | 运营端分页查询全平台退款记录 | Operator, Admin |

- **请求参数**：`orderId`（Guid?）、`status`（RefundStatus?）、`page`、`pageSize`。
- **响应字段**：`RefundListResultDto`，含 `Items`（每项含 `Id`、`RefundNo`、`OrderId`、`UserId`、`Amount`、`Channel`、`Status`（Pending/Refunded/Failed）、`AfterSalesId`、`RequestedAt`、`CompletedAt`）、`Total`、`SuccessRate`。
- **数据加载策略**：进入页面加载近7天退款记录；切换筛选重新请求；统计概览从列表元数据聚合。
- **缓存策略**：不缓存，退款状态实时性强。

## 4. 交互流程
- **主流程**：
  1. 进入页面 → 加载近7天退款记录 → 渲染表格与统计概览
  2. 点击「详情」→ 打开抽屉展示退款信息、关联售后、渠道回写、状态时间线
  3. 切换状态筛选 → 重新请求 → 表格更新
- **分支流程**：
  - 退款失败记录：行标红背景 `#FFF1F0`，抽屉展示失败原因，操作列增加「重试」入口（如支持）
  - 待退款记录：抽屉展示预计退款时间
- **跨页面流转**：点击「订单号」跳转订单管理；点击「售后单」跳转售后处理；点击「渠道」跳转支付渠道配置。
- **状态机可视化**：Pending（待退款）→ Refunded（已退款）/ Failed（退款失败）。失败可重试。

## 6. 视觉规范
- **主色应用**：导出按钮默认色，详情链接主色。
- **状态色**：待退款 `#FAAD14` 橙、已退款 `#52C41A` 绿、退款失败 `#FF4D4F` 红。
- **金额色**：`#FF4D4F` 14px medium。
- **间距**：筛选条与表格 16px，统计概览卡片间距 24px，表格行高 48px，抽屉区块 24px。
- **字体**：退款单号 14px mono，金额 14px `#FF4D4F`，关联售后单 12px mono `#8C8C8C`，时间 12px `#8C8C8C`。
- **图标尺寸**：操作列图标 16px。

## 7. 异常处理与边界
- **加载态**：表格 `<a-spin>` 包裹；抽屉加载 Skeleton。
- **空数据**：列表空显示「暂无退款记录」，按状态筛选提示「该状态下暂无记录」。
- **错误态**：网络错误 `message.error('加载退款记录失败')` + 重试；403 提示无权限。
- **权限控制**：Operator/Admin 可访问；明细含金额字段，运营可见全量。
- **并发与乐观锁**：只读页面无并发。
- **危险操作确认**：无危险操作，仅查询与导出。

## 8. 验收要点
- [ ] 列表支持按退款单号/订单号/状态/时间组合筛选
- [ ] 统计概览展示各状态计数与成功率
- [ ] 详情抽屉展示关联售后与渠道回写时间线
- [ ] 退款失败行标红并展示失败原因
- [ ] 关联售后单号可跳转售后处理页
