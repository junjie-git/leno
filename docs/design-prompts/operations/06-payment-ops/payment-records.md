# 支付记录 - 运营管理后台

## 1. 页面定位
- **所属端**：运营管理后台
- **所属模块**：06-payment-ops 支付运营
- **页面类型**：列表查询页（全平台支付记录）
- **目标用户**：运营管理员（Operator）
- **核心目标**：分页查询全平台支付记录，按用户/渠道/状态/时间过滤，定位支付异常与对账差异，辅助支付链路问题排查。
- **访问入口**：左侧菜单「支付运营 → 支付记录」；支付统计页渠道明细跳转；订单管理页支付方式跳转。
- **实现状态**：✅ 已实现

## 2. 页面布局与信息架构
- **整体布局**：顶部筛选条 + 操作工具栏 + 支付记录表格 + 支付详情抽屉（含渠道回调）。
- **关键区域**：
  - 区域 A（筛选条）：`<a-form inline>` 含支付单号、订单号、用户 ID、支付渠道（微信/支付宝/其他）、支付状态（待支付/已支付/已关闭/已退款）、时间范围、查询/重置
  - 区域 B（工具栏）：导出列表、刷新、统计概览（各状态计数与成功率）
  - 区域 C（支付表格）：`<a-table>` 列含支付单号、订单号、用户、金额、渠道、状态、支付时间、渠道流水号、操作列
  - 区域 D（详情抽屉）：`<a-drawer width="640">` 展示支付基础信息、渠道参数、回调记录、状态变更时间线
- **响应式断点**：≥1200px 抽屉 640px；992-1199px 抽屉 480px。
- **首屏内容**：筛选条 + 已支付状态的近7天记录前 20 条。

## 3. 数据模型与 API 对接
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| GET | `/api/admin/payments` | 运营端分页查询全平台支付记录 | Operator, Admin |

- **请求参数**：`userId`（Guid?）、`channel`（PaymentChannel?）、`status`（PaymentStatus?）、`startDate`（DateTime?）、`endDate`（DateTime?）、`page`、`pageSize`。
- **响应字段**：`PaymentListResultDto`，含 `Items`（每项含 `Id`、`PaymentNo`、`OrderId`、`UserId`、`Amount`、`Channel`、`Status`、`PaidAt`、`ChannelTradeNo`）、`Total`、`SuccessRate`。
- **数据加载策略**：进入页面加载已支付近7天记录；切换筛选重新请求；统计概览从列表元数据聚合。
- **缓存策略**：不缓存，支付状态实时性强。

## 4. 交互流程
- **主流程**：
  1. 进入页面 → 加载已支付近7天记录 → 渲染表格与统计概览
  2. 点击「详情」→ 打开抽屉展示支付信息、渠道参数、回调记录、状态时间线
  3. 切换渠道/状态筛选 → 重新请求 → 表格更新
- **分支流程**：
  - 已退款记录：抽屉展示退款关联的售后单号，可跳转售后处理
  - 异常支付（已支付但订单未变更）：标红行背景 `#FFF1F0`，操作列增加「排查」入口
- **跨页面流转**：点击「订单号」跳转订单管理；点击「退款」跳转退款记录页；点击「渠道」跳转支付渠道配置。
- **状态机可视化**：Pending（待支付）→ Paid（已支付）/ Closed（已关闭）→ Refunded（已退款）。

- **基础组件**：`<a-table>`、`<a-form>`、`<a-input>`、`<a-select>`、`<a-drawer>`、`<a-statistic>`、`<a-timeline>`、`<a-descriptions>`

## 6. 视觉规范
- **主色应用**：导出按钮默认色，详情链接主色。
- **状态色**：待支付 `#FAAD14` 橙、已支付 `#52C41A` 绿、已关闭 `#8C8C8C` 灰、已退款 `#722ED1` 紫。
- **金额色**：`#FF4D4F` 14px medium。
- **间距**：筛选条与表格 16px，统计概览卡片间距 24px，表格行高 48px，抽屉区块 24px。
- **字体**：支付单号 14px mono，金额 14px `#FF4D4F`，渠道流水号 12px mono `#8C8C8C`，时间 12px `#8C8C8C`。
- **图标尺寸**：操作列图标 16px。

## 7. 异常处理与边界
- **加载态**：表格 `<a-spin>` 包裹；抽屉加载 Skeleton。
- **空数据**：列表空显示「暂无支付记录」，按状态筛选提示「该状态下暂无记录」。
- **错误态**：网络错误 `message.error('加载支付记录失败')` + 重试；403 提示无权限。
- **权限控制**：Operator/Admin 可访问；明细含金额字段，运营可见全量。
- **并发与乐观锁**：只读页面无并发。
- **危险操作确认**：无危险操作，仅查询与导出。
