# 卖家统计 - 运营管理后台

## 1. 页面定位
- **所属端**：运营管理后台
- **所属模块**：04-seller-ops 卖家运营
- **页面类型**：看板页（跨店铺卖家经营统计）
- **目标用户**：运营管理员（Operator）
- **核心目标**：跨店铺聚合统计卖家经营指标（GMV、订单数、商品数、评分），识别头部卖家与待治理卖家，辅助运营决策。
- **访问入口**：左侧菜单「卖家运营 → 卖家统计」；店铺治理页「查看统计」跳转。
- **实现状态**：🚧 规划中（跨店铺聚合端点待补充，当前复用 dashboard 共享端点 + 店铺列表聚合）

## 2. 页面布局与信息架构
- **整体布局**：顶部时间筛选条 + 中部 4 张指标卡片（卖家总数/活跃卖家/新增卖家/平均评分）+ 中下卖家排行柱状图 + 右下类目分布饼图 + 底部卖家明细表格。
- **关键区域**：
  - 区域 A（筛选条）：`<DateTimeRangePicker>` 预设今日/近7天/近30天/本月，含主营类目筛选
  - 区域 B（指标卡片）：4 列 `<DashboardCard>`，活跃卖家数附环比趋势
  - 区域 C（卖家排行）：`<ChartBar>` 横向柱状图，Top 10 卖家按 GMV 降序
  - 区域 D（类目分布）：`<ChartPie>` 环形图，展示卖家按主营类目分布
  - 区域 E（明细表格）：`<a-table>` 展示卖家名称、店铺、类目、GMV、订单数、商品数、评分、状态、操作列（查看治理）
- **响应式断点**：≥1200px 全展开；992-1199px 图表上下堆叠。
- **首屏内容**：时间筛选 + 4 张指标卡片 + Top 10 卖家排行。
- **线框图描述**：

## 3. 数据模型与 API 对接
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| GET | `/api/admin/dashboard/shop-ranking` | 查询店铺排行（跨店铺 GMV/订单聚合） | Operator, Admin |
| GET | `/api/admin/shops` | 分页查询店铺列表（含状态/类目过滤） | Admin, Operator |

- **规划补充端点**（🚧）：`GET /api/admin/seller-statistics/overview`，跨店铺聚合卖家总数/活跃数/新增数/平均评分，参数 `start`/`end`/`category`。
- **请求参数**：dashboard 端点含 `start`（DateTime?）、`end`（DateTime?）、`top`（int，默认 10）；店铺查询含 `Keyword`、`Status`、`MainCategory`、`Page`、`PageSize`。
- **响应字段**：`DashboardReportDto`（ReportType=ShopRanking），Metrics 含 `total_sellers`、`active_sellers`、`new_sellers`、`avg_rating`、`top_shops`（按 GMV 排序的店铺数组）、`category_distribution`。
- **数据加载策略**：进入页面加载近30天数据；切换时间或类目重新请求；表格分页独立请求店铺列表。
- **缓存策略**：Pinia 缓存键 `seller_stats_{start}_{end}_{category}`，过期 10 分钟。

## 4. 交互流程
- **主流程**：
  1. 进入页面 → 加载近30天卖家统计数据 → 渲染卡片、图表、表格
  2. 切换时间预设或类目 → 重新请求 → 图表过渡动画
  3. 点击表格行卖家 → 跳转店铺治理（携带卖家 ID 筛选）
- **分支流程**：
  - 评分 < 4.0 的卖家行高亮 `#FFF1F0` 背景，标记「待治理」标签
  - 类目筛选为空时展示全平台分布
- **跨页面流转**：点击「查看治理」跳转店铺治理页；点击「商品数」跳转商品审核页。
- **状态机可视化**：无状态字段，纯统计展示。

## 6. 视觉规范
- **主色应用**：柱状图主色 `#1677FF`，待治理标签 `#FF4D4F`。
- **状态色**：活跃 `#52C41A`、待治理 `#FF4D4F`、新增 `#1677FF`。
- **间距**：卡片间距 24px，表格行高 48px，图表高度 300px。
- **字体**：卡片数值 24px semibold，表格正文 14px，评分 16px semibold，辅助文字 12px `#8C8C8C`。
- **图标尺寸**：告警图标 16px。

## 7. 异常处理与边界
- **加载态**：首屏 Skeleton 模拟卡片与图表；表格 `<a-spin>` 包裹。
- **空数据**：卡片显示 `--`，图表 EmptyState，表格显示「暂无卖家数据」。
- **错误态**：网络错误 `message.error('加载卖家统计失败')` + 重试；403 提示无权限。
- **权限控制**：Operator/Admin 可访问；明细含 GMV 字段，运营可见全量。
- **并发与乐观锁**：只读页面无并发。
- **危险操作确认**：无危险操作。
- **规划说明**：跨店铺聚合端点上线前，前端基于 dashboard shop-ranking 与店铺列表二次聚合，存在轻微性能损耗。
