# 通知配置 - 运营管理后台

## 1. 页面定位
- **所属端**：运营管理后台
- **所属模块**：07-notification-ops 通知运营
- **页面类型**：配置管理页（渠道配置 + 测试发送）
- **目标用户**：运营管理员（Operator）
- **核心目标**：维护各通知渠道（短信/邮件/站内信/推送）的配置（API Key/签名/发件人等），支持测试发送验证配置正确性。
- **访问入口**：左侧菜单「通知运营 → 通知配置」；通知记录页失败记录排查跳转。
- **实现状态**：✅ 已实现

## 2. 页面布局与信息架构
- **整体布局**：左侧渠道列表 + 右侧配置详情/编辑面板 + 测试发送对话框。
- **关键区域**：
  - 区域 A（渠道列表）：左侧 280px 宽，列出全部通知渠道卡片（短信/邮件/站内信/推送），每卡片含渠道图标、名称、配置状态点
  - 区域 B（详情面板）：右侧展示选中渠道的配置项列表（敏感字段脱敏）、最后更新人与时间
  - 区域 C（编辑表单）：右侧切换为编辑模式，含各配置项输入（敏感字段脱敏可更新）、状态开关
  - 区域 D（测试发送对话框）：`<a-modal>` 含测试接收人（手机号/邮箱）、测试模板内容、发送按钮、返回结果展示
- **响应式断点**：≥1200px 左右分栏；992-1199px 渠道列表折叠为下拉选择。
- **首屏内容**：渠道列表 + 默认选中短信渠道的配置详情。
- **线框图描述**：

## 3. 数据模型与 API 对接
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| GET | `/api/admin/notification-config` | 获取指定渠道配置（敏感字段脱敏） | Operator, Admin |
| PUT | `/api/admin/notification-config` | 更新指定渠道配置 | Operator, Admin |
| POST | `/api/admin/notification-config/test` | 测试发送验证配置 | Operator, Admin |

- **请求参数**：`channel`（NotificationChannel，query）；更新请求体 `SaveNotificationConfigDto` 含配置项键值对（敏感字段明文传输）；测试请求体 `TestSendRequestDto` 含 `Recipient`（手机号/邮箱）、`Content`。
- **响应字段**：`NotificationConfigDto`，含 `Channel`、`Configs`（`ConfigItem[]`，每项含 `Key`、`Value`（脱敏）、`IsSensitive`）、`UpdatedBy`、`UpdatedAt`；测试返回 `TestSendResultDto` 含 `Success`、`Message`、`ProviderResponse`。
- **数据加载策略**：进入页面加载全部渠道配置；选中渠道过滤展示；更新后局部刷新。
- **缓存策略**：不缓存，配置变更需实时生效。

## 4. 交互流程
- **主流程**：
  1. 进入页面 → 加载全部渠道配置 → 渠道列表渲染 → 默认选中短信渠道
  2. 点击渠道卡片 → 右侧展示该渠道配置项详情（敏感字段脱敏）
  3. 点击「编辑」→ 切换为编辑模式 → 修改配置项 → `<IdempotencyButton>` 提交 → 局部刷新
  4. 点击「测试发送」→ 弹出对话框 → 输入测试接收人与内容 → 发送 → 展示返回结果
- **分支流程**：
  - 敏感字段编辑：脱敏显示 `****`，点击编辑后清空可重新输入，留空表示不修改
  - 测试发送失败：展示具体错误信息（如 API Key 无效/接收人格式错误）
  - 未配置渠道：状态显示「未配置」，编辑按钮置灰提示「请先完成配置」
- **跨页面流转**：测试发送成功后可跳转通知记录页查看发送结果。
- **状态机可视化**：渠道配置状态 未配置 → 已配置（编辑提交后）。

## 6. 视觉规范
- **主色应用**：编辑/测试发送按钮主色 `#1677FF`。
- **状态色**：已配置 `#52C41A` 绿点、未配置 `#FAAD14` 橙点（渠道列表卡片左侧 6px 圆点）。
- **渠道色**：短信 `#52C41A`、邮件 `#1677FF`、站内信 `#722ED1`、推送 `#FAAD14`。
- **敏感字段**：脱敏显示 `****` 灰色 `#8C8C8C`，编辑时清空为可输入。
- **间距**：渠道列表项间距 8px，详情面板区块 24px，配置项行高 48px。
- **字体**：渠道名称 14px medium，配置键 14px mono，配置值 14px `#000000D9`，脱敏值 `#8C8C8C`，更新时间 12px `#8C8C8C`。
- **图标尺寸**：操作按钮图标 16px，渠道图标 24px。

## 7. 异常处理与边界
- **加载态**：渠道列表与详情面板 `<a-spin>` 包裹；测试发送 loading。
- **空数据**：渠道列表空显示「暂无通知渠道配置」。
- **错误态**：测试发送失败展示错误信息；更新失败 `message.error('配置更新失败，请重试')`。
- **权限控制**：Operator/Admin 可访问；编辑/测试需 `notification:config` 权限。
- **并发与乐观锁**：编辑提交基于聚合版本校验，冲突提示刷新。
- **危险操作确认**：测试发送为可选二次确认（避免误发短信）；配置更新记录审计日志。
- **安全边界**：敏感字段传输加密（HTTPS），脱敏展示防止泄露。
