# 待办工作台 - 运营管理后台

## 1. 页面定位
- **所属端**：运营管理后台
- **所属模块**：09-account 个人中心
- **页面类型**：工作台页（待办聚合 + 快捷入口）
- **目标用户**：运营管理员（Operator）
- **核心目标**：聚合各业务域待办（待审核商品/入驻/售后/评价/通知死信），按优先级展示，提供快捷处理入口，提升运营效率。
- **访问入口**：登录后默认首页（`/account/todo`）；Header 待办铃铛点击跳转。
- **实现状态**：➕ 补充功能（聚合各业务域列表端点，无独立待办端点）

## 2. 页面布局与信息架构
- **整体布局**：顶部待办概览卡片 + 中部待办分类列表 + 底部快捷操作区。
- **关键区域**：
  - 区域 A（概览卡片）：4 列卡片展示待审核商品数、待审核入驻数、待介入售后数、待审核评价数，每卡片含数字与跳转链接
  - 区域 B（待办分类列表）：`<a-tabs>` 按业务域分类（商品/卖家/订单/通知），每分类展示 Top 10 待办项
  - 区域 C（待办项卡片）：每项含标题、来源、优先级标签、提交时间、处理按钮
  - 区域 D（快捷操作）：常用操作入口（新增活动/发放优惠券/手动发积分/重发死信）
- **响应式断点**：≥1200px 概览卡片 4 列；992-1199px 概览卡片 2 列；<992px 1 列。
- **首屏内容**：概览卡片 + 商品审核待办 Top 10。
- **线框图描述**：

```

│ →去处理   │ →去处理   │ →去处理   │ →去处理   │
```

## 3. 数据模型与 API 对接
- **主要 API**（聚合各业务域列表端点）：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| GET | `/api/admin/products/all` | 查询待审核商品（Status=PendingAudit） | Admin, Operator |
| GET | `/api/admin/shops` | 查询待审核入驻（Status=PendingReview） | Admin, Operator |
| GET | `/api/admin/after-sales` | 查询待介入售后（Status=待介入） | Operator, Admin |
| GET | `/api/admin/reviews` | 查询待审核评价（Status=Pending） | Operator, Admin |
| GET | `/api/notifications/records` | 查询死信通知（Status=DeadLetter） | Operator, Admin |

- **请求参数**：各端点按待办状态过滤，`page=1`、`pageSize=10` 仅取 Top 10；概览卡片仅取 `Total` 计数。
- **响应字段**：复用各业务域列表 DTO，提取 `Total` 与 `Items` 前 10 项。
- **数据加载策略**：进入页面并行请求 5 个端点获取计数与 Top 10；每 5 分钟自动刷新计数（Header 铃铛同步）。
- **缓存策略**：待办计数缓存于 Pinia，5 分钟过期，Header 铃铛徽标共享。

## 4. 交互流程
- **主流程**：
  1. 进入页面 → 并行加载 5 类待办计数与 Top 10 → 渲染概览卡片与列表
  2. 点击概览卡片「去处理」→ 跳转对应审核页（携带待办状态筛选）
  3. 切换待办分类选项卡 → 展示该分类 Top 10
  4. 点击待办项「处理」→ 跳转对应审核页详情
- **分支流程**：
  - 待办为空：概览卡片显示 0，列表显示 EmptyState「暂无待办」
  - 快捷操作：点击新增活动跳转促销活动页；发券跳转优惠券管理；发积分跳转积分规则；重发死信跳转通知记录
  - 高优先级待办：超 24 小时未处理的待审核项标记红色「超时」标签
- **跨页面流转**：所有待办项点击跳转对应业务审核页；快捷操作跳转对应管理页。
- **状态机可视化**：无状态字段，待办项处理后从列表移除（重新加载时刷新）。

- **空状态**：`EmptyState` title="暂无待办"

## 6. 视觉规范
- **主色应用**：概览卡片数字主色 `#1677FF`，超时标签 `#FF4D4F`。
- **优先级色**：高 `#FF4D4F` 红、中 `#FAAD14` 橙、低 `#52C41A` 绿。
- **状态色**：待办计数 >0 `#FF4D4F` 红色徽标，=0 `#8C8C8C` 灰。
- **间距**：概览卡片间距 24px，待办项间距 12px，快捷操作按钮间距 8px。
- **字体**：概览数字 32px semibold `#1677FF`，待办标题 14px medium，来源 12px `#8C8C8C`，时间 12px `#8C8C8C`。
- **图标尺寸**：概览卡片图标 24px，待办项图标 16px。

## 7. 异常处理与边界
- **加载态**：概览卡片 Skeleton；待办列表 `<a-spin>` 包裹。
- **空数据**：所有待办为 0 时概览卡片显示 0，列表显示「暂无待办」+ 引导快捷操作。
- **错误态**：单个端点失败不影响其他端点展示，失败卡片显示 `--` + 重试。
- **权限控制**：Operator/Admin 可访问；快捷操作按权限显隐（新增活动需 `promotion:manage` 等）。
- **并发与乐观锁**：只读页面无并发；自动刷新 5 分钟间隔避免频繁请求。
- **危险操作确认**：无危险操作（仅跳转）。
