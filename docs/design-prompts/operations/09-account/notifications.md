# 通知中心 - 运营管理后台

## 1. 页面定位
- **所属端**：运营管理后台
- **所属模块**：09-account 个人中心
- **页面类型**：列表页（站内信查询 + 已读管理）
- **目标用户**：运营管理员（Operator）
- **核心目标**：查询当前运营账号的站内信通知，支持按已读状态过滤、批量标记已读、全部已读，掌握系统与业务通知。
- **访问入口**：Header 通知铃铛点击下拉预览 + 「查看全部」跳转；左侧菜单「个人中心 → 通知中心」。
- **实现状态**：✅ 已实现

## 2. 页面布局与信息架构
- **整体布局**：顶部筛选条 + 操作工具栏 + 通知列表 + 通知详情抽屉。
- **关键区域**：
  - 区域 A（筛选条）：`<a-form inline>` 含已读状态（全部/未读/已读）、通知类型（系统/业务/审核）、时间范围、查询/重置
  - 区域 B（工具栏）：全部标记已读、批量标记已读、刷新、未读计数徽标
  - 区域 C（通知列表）：`<a-list>` 展示通知项，每项含图标、标题、摘要、时间、已读状态点、操作（查看/标记已读）
  - 区域 D（详情抽屉）：`<a-drawer width="480">` 展示通知全文、来源、时间、关联业务跳转
- **响应式断点**：≥1200px 列表全展开；992-1199px 抽屉宽度自适应。
- **首屏内容**：筛选条 + 全部通知列表前 20 条（未读置顶）。
- **线框图描述**：

```

│ [已读状态▼][类型▼][时间范围] [查询][重置]         │

```

## 3. 数据模型与 API 对接
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| GET | `/api/notifications` | 分页查询我的站内信 | Buyer, Seller, Operator, Admin |
| GET | `/api/notifications/unread-count` | 获取未读计数 | Buyer, Seller, Operator, Admin |
| POST | `/api/notifications/read` | 按记录标识批量标记已读 | Buyer, Seller, Operator, Admin |
| POST | `/api/notifications/read-all` | 全部标记已读 | Buyer, Seller, Operator, Admin |

- **请求参数**：查询参数 `isRead`（bool?）、`page`、`pageSize`；批量已读请求体 `MarkAsReadDto` 含 `RecordIds`（Guid 数组）。
- **响应字段**：`NotificationListResultDto`，含 `Items`（每项含 `Id`、`Title`、`Summary`、`Type`、`IsRead`、`CreatedAt`、`BusinessRef`）、`Total`、`UnreadCount`。
- **数据加载策略**：进入页面加载全部通知（未读置顶）；标记已读后局部更新状态；Header 铃铛未读计数同步。
- **缓存策略**：未读计数缓存于 Pinia，30 秒过期，Header 铃铛轮询共享。

## 4. 交互流程
- **主流程**：
  1. 进入页面 → 加载全部通知 → 渲染列表（未读置顶）
  2. 点击通知「查看」→ 打开抽屉展示全文 → 自动标记已读
  3. 点击「标记已读」→ 调用 read → 状态点变灰
  4. 点击「全部标记已读」→ 调用 read-all → 列表全部已读
- **分支流程**：
  - 批量标记已读：勾选多行 → 批量标记 → 串行调用
  - 关联业务跳转：详情抽屉展示关联业务链接（如审核通知跳转审核页）
  - Header 铃铛预览：下拉展示未读 Top 5，点击跳转通知中心
- **跨页面流转**：点击关联业务链接跳转对应审核页。
- **状态机可视化**：通知状态 未读 → 已读（标记后不可逆）。

## 6. 视觉规范
- **主色应用**：标记已读按钮默认色，全部标记已读按钮主色 `#1677FF`。
- **状态色**：未读红点 `#FF4D4F`、已读灰点 `#8C8C8C`（列表项左侧 6px 圆点）。
- **通知类型色**：系统 `#1677FF` 蓝、业务 `#52C41A` 绿、审核 `#FAAD14` 橙（`<a-tag>` 区分）。
- **间距**：筛选条与列表 16px，列表项间距 12px，抽屉区块 24px。
- **字体**：通知标题 14px medium（未读加粗），摘要 14px `#000000D9`，时间 12px `#8C8C8C`。
- **图标尺寸**：通知项图标 16px，状态点 6px。

## 7. 异常处理与边界
- **加载态**：列表 `<a-spin>` 包裹；标记已读按钮 loading。
- **空数据**：列表空显示「暂无通知」，按已读筛选提示「无未读通知」。
- **错误态**：标记已读失败 `message.error('操作失败，请重试')`；Header 铃铛计数加载失败静默重试。
- **权限控制**：已认证用户可访问自身通知（Operator/Admin/Seller/Buyer 角色均支持）。
- **并发与乐观锁**：标记已读幂等，重复操作无副作用。
- **危险操作确认**：全部标记已读为可选二次确认（避免误操作丢失未读状态提示）。
