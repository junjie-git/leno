# 店铺排行 - 运营管理后台

## 1. 页面定位
- **所属端**：运营管理后台
- **所属模块**：01-dashboard 数据看板
- **页面类型**：看板页
- **目标用户**：运营管理员（Operator）
- **核心目标**：查看店铺销售排行 Top N，识别头部与尾部卖家，辅助治理决策。
- **访问入口**：左侧菜单「数据看板 → 店铺排行」；运营总览页店铺卡片跳转。
- **实现状态**：✅ 已实现

## 2. 页面布局与信息架构
- **整体布局**：顶部时间筛选条 + Top N 选择器 + 中部 Top 10 店铺柱状图 + 下部店铺排行明细表格。
- **关键区域**：
  - 区域 A（筛选条）：`<DateTimeRangePicker>` 预设今日/昨日/近7天/近30天/本月 + `<a-select>` 选择 Top 10/20/50
  - 区域 B（柱状图）：`<ChartBar>` 横向柱状图展示 Top N 店铺 GMV，柱条按店铺名标注
  - 区域 C（明细表格）：`<a-table>` 展示排名、店铺名称、卖家账号、GMV、订单量、客单价、好评率、状态
- **响应式断点**：≥1200px 全展开；992-1199px 表格横向滚动。
- **首屏内容**：时间筛选 + Top N 选择 + Top 10 柱状图。
- **线框图描述**：

```
┌─────────────────────────────────────────────┐
│ [今日][昨日][近7天][近30天][本月]  Top[10▾] │
├─────────────────────────────────────────────┤
│ 店铺GMV排行(横向柱状图)                       │
│ 店铺A ████████████████████ ¥128,560          │
│ 店铺B █████████████ ¥86,200                  │

├─────────────────────────────────────────────┤
│ 排行明细表格                                  │

└─────────────────────────────────────────────┘
```

## 3. 数据模型与 API 对接
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| GET | `/api/admin/dashboard/shop-ranking` | 查询店铺排行 TopN | Operator, Admin |

- **请求参数**：`start`（DateTime?）、`end`（DateTime?），默认近7天。Top N 由前端从 Metrics 解析（后端返回固定 Top 50，前端切片）。
- **响应字段**：`DashboardReportDto`，`ReportType` 为 `ShopRanking`，Metrics 含 `shop_ranking`（数组，每项含 `shop_id`/`shop_name`/`seller_account`/`gmv`/`order_count`/`avg_order_value`/`positive_rate`/`status`）。
- **数据加载策略**：进入页面加载默认时间范围；Top N 切换前端切片无需重新请求。
- **缓存策略**：Pinia 缓存键 `shop_ranking_{start}_{end}`，过期 5 分钟。

## 4. 交互流程
- **主流程**：
  1. 进入页面 → 加载近7天店铺排行 → 渲染柱状图与表格
  2. 切换时间预设 → 重新请求
  3. 切换 Top N 选择器 → 前端切片重新渲染柱状图
  4. 点击表格行 → 跳转店铺治理页详情（携带 shop_id）
- **分支流程**：
  - 店铺状态为「已暂停」或「已关闭」：表格行状态列标红/灰
  - 店铺数 < Top N：柱状图只展示实际数量
- **跨页面流转**：点击表格行跳转店铺治理页（`/seller-ops/shop-governance/{shopId}`）。
- **状态机可视化**：表格状态列使用 StatusTag（type='shop'）展示待审核/营业中/已暂停/已关闭/资质过期。

- **状态色**：营业中 `#52C41A`，已暂停 `#FAAD14`，已关闭 `#8C8C8C`，资质过期 `#FF4D4F`。

- **图标尺寸**：无。

## 7. 异常处理与边界
- **加载态**：首屏 Skeleton；切换时间图表 `<a-spin>`。
- **空数据**：柱状图与表格 EmptyState。
- **错误态**：网络错误 `message.error('加载店铺排行失败')` + 重试。
- **权限控制**：Operator/Admin 可访问；卖家账号字段完整展示（运营可见）。
- **并发与乐观锁**：只读无并发。
- **危险操作确认**：无危险操作。
