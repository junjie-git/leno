# 运营总览 - 运营管理后台

## 1. 页面定位
- **所属端**：运营管理后台
- **所属模块**：01-dashboard 数据看板
- **页面类型**：看板页
- **目标用户**：运营管理员（Operator）
- **核心目标**：一眼掌握平台当日订单量、GMV、转化率等核心运营指标，辅助决策。
- **访问入口**：左侧菜单「数据看板 → 运营总览」；登录后默认首页；Header 待办铃铛旁的快捷入口。
- **实现状态**：✅ 已实现

## 2. 页面布局与信息架构
- **整体布局**：顶部时间范围筛选条 + 中部 4 张核心指标卡片区 + 下部 GMV 趋势折线图 + 右下订单来源分布饼图。
- **关键区域**：
  - 区域 A（筛选条）：`<DateTimeRangePicker>`（见 shared/components.md §4）预设今日/昨日/近7天/近30天/本月，默认近7天
  - 区域 B（指标卡片）：4 列等宽 `<DashboardCard>`（见 shared/components.md §8），分别展示订单量、GMV、转化率、客单价
  - 区域 C（趋势图）：左侧 16 栅格 `<ChartLine>`（见 shared/components.md §7.1）展示 GMV 与订单量双轴趋势
  - 区域 D（分布图）：右侧 8 栅格 `<ChartPie>` 展示订单来源分布（APP/Web/小程序）
- **响应式断点**：≥1200px 全展开；992-1199px 指标卡片改为 2×2 网格，图表上下堆叠。
- **首屏内容**：时间筛选 + 4 张指标卡片 + 趋势图前 7 天数据。
- **线框图描述**：

## 3. 数据模型与 API 对接
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| GET | `/api/admin/dashboard/overview` | 查询运营总览（订单量/GMV/转化率） | Operator, Admin |

- **请求参数**：`start`（DateTime?，开始时间）、`end`（DateTime?，结束时间），默认近7天。
- **响应字段**：`DashboardReportDto`，含 `ReportId`、`ReportType`（OrderGmv）、`Granularity`、`GeneratedAt`、`PeriodStart`、`PeriodEnd`、`Metrics`（`MetricItemDto[]`，每项含 `Key`/`Value`/`Unit`）。Metrics 的 Key 包括 `order_count`、`gmv`、`conversion_rate`、`avg_order_value`、`gmv_trend`、`order_source_distribution`。
- **数据加载策略**：进入页面立即加载，时间范围变化重新加载；趋势图与分布图并行请求同一端点，从 Metrics 解析。
- **缓存策略**：前端 Pinia `useDashboardStore` 缓存最近一次响应，键为 `overview_{start}_{end}`，过期 5 分钟。

## 4. 交互流程
- **主流程**：
  1. 进入页面 → 加载默认近7天数据 → 渲染指标卡片与图表
  2. 切换时间预设（如「今日」）→ 重新请求 → 图表过渡动画 300ms
  3. 自定义时间范围 → 点击「查询」按钮 → 重新请求
- **分支流程**：
  - 时间范围内无数据：指标卡片显示 `--`，图表显示 EmptyState
  - 请求超时（>10s）：显示重试按钮
- **跨页面流转**：点击指标卡片「订单量」跳转订单管理页（携带时间范围参数）；点击「GMV」跳转支付统计页。
- **状态机可视化**：无状态字段，纯只读看板。

## 5. 组件清单
- **基础组件**：`<a-card>`、`<a-row>`、`<a-col>`、`<a-spin>`
- **业务组件**：
  - `DashboardCard`（见 shared/components.md §8）— 指标卡片，含标题/数值/单位/趋势
  - `DateTimeRangePicker`（见 shared/components.md §4）— 时间范围筛选
  - `EmptyState`（见 shared/components.md §5）— 无数据占位
- **图表组件**：
  - `ChartLine`（见 shared/components.md §7.1）— GMV 与订单量双轴趋势，smooth 曲线
  - `ChartPie`（见 shared/components.md §7.2）— 订单来源分布，环形图
- **图标使用**：`@ant-design/icons-vue` 的 `ArrowUpOutlined`/`ArrowDownOutlined` 趋势箭头
- **空状态**：`EmptyState` title="暂无数据" description="当前时间范围内无运营数据"

## 6. 视觉规范
- **主色应用**：趋势图主线 `#1677FF`，指标卡片数值 `#000000D9`，趋势上升 `#52C41A`、下降 `#FF4D4F`。
- **状态色**：转化率下降用 `#FF4D4F` 警示，GMV 上升用 `#52C41A` 正向。
- **间距**：卡片间距 `24px`，卡片内边距 `16px`，图表高度 `300px`。
- **字体**：卡片标题 14px `#8C8C8C`，数值 24px semibold `#000000D9`，趋势文字 12px。
- **图标尺寸**：趋势箭头 12px，与文字基线对齐。

## 7. 异常处理与边界
- **加载态**：首屏 `<a-skeleton :active="true">` 模拟卡片与图表布局；切换时间范围时图表显示 `<a-spin>`。
- **空数据**：指标卡片显示 `--`，图表区域 `EmptyState` 引导调整时间范围。
- **错误态**：网络错误 `message.error('加载运营数据失败')` + 重试按钮；权限不足（403）`message.warning('无权限访问')`。
- **权限控制**：页面级 Operator/Admin 角色校验；字段级无脱敏（运营可见全量聚合数据）。
- **并发与乐观锁**：只读页面无并发冲突。
- **危险操作确认**：无危险操作。
