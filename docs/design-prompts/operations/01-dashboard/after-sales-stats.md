# 售后统计 - 运营管理后台

## 1. 页面定位
- **所属端**：运营管理后台
- **所属模块**：01-dashboard 数据看板
- **页面类型**：看板页
- **目标用户**：运营管理员（Operator）
- **核心目标**：监控售后单量、退款金额、售后率与处理时效，评估售后服务质量。
- **访问入口**：左侧菜单「数据看板 → 售后统计」；运营总览页售后卡片跳转。
- **实现状态**：✅ 已实现

## 2. 页面布局与信息架构
- **整体布局**：顶部时间筛选条 + 中部 4 张指标卡片（售后单量/退款金额/售后率/平均处理时长）+ 中下售后趋势折线图 + 右下售后类型分布饼图 + 底部状态分布表格。
- **关键区域**：
  - 区域 A（筛选条）：`<DateTimeRangePicker>` 预设今日/昨日/近7天/近30天/本月
  - 区域 B（指标卡片）：4 列 `<DashboardCard>`，售后率 = 售后单量/订单量
  - 区域 C（趋势图）：`<ChartLine>` 双系列展示每日售后单量与退款金额（双轴）
  - 区域 D（类型分布）：`<ChartPie>` 展示售后类型（仅退款/退货退款/换货）
  - 区域 E（状态表格）：`<a-table>` 展示各状态的售后单量与占比
- **响应式断点**：≥1200px 全展开；992-1199px 图表上下堆叠。
- **首屏内容**：时间筛选 + 4 张指标卡片 + 趋势图。
- **线框图描述**：

```
┌─────────────────────────────────────────────┐
│ [今日][昨日][近7天][近30天][本月]            │
├──────────┬──────────┬──────────┬──────────┤
│ 售后单量  │ 退款金额 │ 售后率   │ 平均处理  │
│ 86       │ ¥12,560  │ 6.7%     │ 2.3天    │
│ ↑5.1%    │ ↑8.2%   │ ↑0.3%   │ ↓0.2天   │
├────────────────────────┬────────────────────┤
│ 售后趋势(折线图)       │ 售后类型(饼图)     │
├─────────────────────────────────────────────┤
│ 状态分布表格                                  │
└─────────────────────────────────────────────┘
```

## 3. 数据模型与 API 对接
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| GET | `/api/admin/dashboard/after-sales-stats` | 查询售后统计（售后量/退款金额） | Operator, Admin |

- **请求参数**：`start`（DateTime?）、`end`（DateTime?），默认近7天。
- **响应字段**：`DashboardReportDto`，`ReportType` 为 `AfterSalesVolume`，Metrics 含 `after_sales_count`、`refund_amount`、`after_sales_rate`、`avg_process_hours`、`after_sales_trend`、`type_distribution`、`status_distribution`。
- **数据加载策略**：进入页面加载默认时间范围；趋势图与分布图从同一响应解析。
- **缓存策略**：Pinia 缓存键 `after_sales_stats_{start}_{end}`，过期 5 分钟。

## 4. 交互流程
- **主流程**：
  1. 进入页面 → 加载近7天售后统计数据 → 渲染卡片、图表、表格
  2. 切换时间预设 → 重新请求
  3. 点击「售后单量」卡片 → 跳转售后处理页（携带时间范围）
- **分支流程**：
  - 售后率 > 10%：卡片数值标红，提示「售后率偏高」
  - 平均处理时长 > 3 天：标黄预警
- **跨页面流转**：点击「售后单量」跳转售后处理页；点击「退款金额」跳转退款记录页。
- **状态机可视化**：底部表格展示待审核/待退货/待退款/已完成/已拒绝/已取消各状态分布。

## 6. 视觉规范
- **主色应用**：趋势图售后单量线 `#1677FF`，退款金额线 `#FAAD14`。
- **状态色**：售后率偏高 `#FF4D4F`，处理时长偏长 `#FAAD14`，正常 `#52C41A`。
- **间距**：卡片间距 `24px`，图表高度 `300px`。
- **字体**：卡片数值 24px semibold，表格 14px。
- **图标尺寸**：预警 16px。

## 7. 异常处理与边界
- **加载态**：首屏 Skeleton；切换时间图表 `<a-spin>`。
- **空数据**：卡片 `--`，图表 EmptyState。
- **错误态**：网络错误 `message.error('加载售后统计失败')` + 重试。
- **权限控制**：Operator/Admin 可访问。
- **并发与乐观锁**：只读无并发。
- **危险操作确认**：无危险操作。

- [ ] 售后率 > 10% 时卡片标红预警
