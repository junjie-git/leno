# 积分统计 - 运营管理后台

## 1. 页面定位
- **所属端**：运营管理后台
- **所属模块**：01-dashboard 数据看板
- **页面类型**：看板页
- **目标用户**：运营管理员（Operator）
- **核心目标**：监控平台积分发放量、消耗量与净增量，评估积分体系健康度。
- **访问入口**：左侧菜单「数据看板 → 积分统计」；运营总览页积分卡片跳转。
- **实现状态**：✅ 已实现

## 2. 页面布局与信息架构
- **整体布局**：顶部时间筛选条 + 中部 3 张指标卡片（发放量/消耗量/净增量）+ 下部积分流水趋势折线图 + 右下发放来源分布饼图。
- **关键区域**：
  - 区域 A（筛选条）：`<DateTimeRangePicker>` 预设今日/昨日/近7天/近30天/本月
  - 区域 B（指标卡片）：3 列 `<DashboardCard>`，发放量与消耗量含环比趋势
  - 区域 C（趋势图）：`<ChartLine>` 双系列展示每日发放与消耗，smooth 曲线
  - 区域 D（分布图）：`<ChartPie>` 展示发放来源分布（签到/购物返积分/任务/活动奖励）
- **响应式断点**：≥1200px 全展开；992-1199px 图表上下堆叠。
- **首屏内容**：时间筛选 + 3 张指标卡片 + 趋势图前 7 天数据。
- **线框图描述**：

```
┌─────────────────────────────────────────────┐
│ [今日][昨日][近7天][近30天][本月]            │
├──────────┬──────────┬──────────┤
│ 发放量    │ 消耗量   │ 净增量   │
│ 128,560  │ 56,200   │ 72,360   │
│ ↑15.2%   │ ↑8.1%    │ ↑22.3%  │
├────────────────────────┬────────────────────┤
│ 发放/消耗趋势(折线图)  │ 发放来源分布(饼图) │
└────────────────────────┴────────────────────┘
```

## 3. 数据模型与 API 对接
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| GET | `/api/admin/dashboard/points-stats` | 查询积分发放量统计 | Operator, Admin |

- **请求参数**：`start`（DateTime?）、`end`（DateTime?），默认近7天。
- **响应字段**：`DashboardReportDto`，`ReportType` 为 `PointsIssued`，Metrics 含 `points_issued`、`points_consumed`、`points_net`、`points_trend`（每日发放/消耗序列）、`source_distribution`（发放来源分布）。
- **数据加载策略**：进入页面加载默认时间范围；趋势图与分布图从同一响应解析。
- **缓存策略**：Pinia 缓存键 `points_stats_{start}_{end}`，过期 5 分钟。

## 4. 交互流程
- **主流程**：
  1. 进入页面 → 加载近7天积分统计数据 → 渲染卡片与图表
  2. 切换时间预设 → 重新请求 → 图表过渡
  3. 点击趋势图数据点 → `<a-tooltip>` 展示当日明细
- **分支流程**：
  - 净增量为负：卡片数值标红，提示「消耗超过发放」
  - 无数据：卡片显示 `--`，图表 EmptyState
- **跨页面流转**：点击「发放量」跳转积分规则页（如已实现）或会员运营模块。
- **状态机可视化**：无状态字段。

## 5. 组件清单
- **基础组件**：`<a-card>`、`<a-row>`、`<a-col>`、`<a-tooltip>`
- **业务组件**：
  - `DashboardCard`（见 shared/components.md §8）— 指标卡片
  - `DateTimeRangePicker`（见 shared/components.md §4）— 时间筛选
  - `EmptyState`（见 shared/components.md §5）— 无数据占位
- **图表组件**：
  - `ChartLine`（见 shared/components.md §7.1）— 发放与消耗双系列趋势
  - `ChartPie`（见 shared/components.md §7.2）— 发放来源环形图
- **图标使用**：`ArrowUpOutlined`/`ArrowDownOutlined` 趋势箭头
- **空状态**：`EmptyState` title="暂无积分数据"

## 6. 视觉规范
- **主色应用**：发放量折线 `#1677FF`，消耗量折线 `#FAAD14`，净增量正向 `#52C41A`、负向 `#FF4D4F`。
- **状态色**：净增量负值用 `#FF4D4F` 警示。
- **间距**：卡片间距 `24px`，图表高度 `300px`。
- **字体**：卡片数值 24px semibold，图例 12px。
- **图标尺寸**：趋势箭头 12px。

## 7. 异常处理与边界
- **加载态**：首屏 Skeleton；切换时间范围图表 `<a-spin>`。
- **空数据**：卡片 `--`，图表 EmptyState。
- **错误态**：网络错误 `message.error('加载积分统计失败')` + 重试。
- **权限控制**：Operator/Admin 可访问。
- **并发与乐观锁**：只读无并发。
- **危险操作确认**：无危险操作。
