# 通知送达率 - 运营管理后台

## 1. 页面定位
- **所属端**：运营管理后台
- **所属模块**：01-dashboard 数据看板
- **页面类型**：看板页
- **目标用户**：运营管理员（Operator）
- **核心目标**：监控各通知渠道（短信/邮件/站内信/Push）的送达率与延迟，发现投递异常。
- **访问入口**：左侧菜单「数据看板 → 通知送达率」；运营总览页通知卡片跳转。
- **实现状态**：✅ 已实现

## 2. 页面布局与信息架构
- **整体布局**：顶部时间筛选条 + 中部 4 张渠道送达率卡片（短信/邮件/站内信/Push）+ 下部送达率趋势折线图 + 右下失败原因分布饼图 + 底部渠道明细表格。
- **关键区域**：
  - 区域 A（筛选条）：`<DateTimeRangePicker>` 预设今日/昨日/近7天/近30天/本月
  - 区域 B（渠道卡片）：4 列 `<DashboardCard>`，每张含 `<ChartGauge>` 送达率仪表盘
  - 区域 C（趋势图）：`<ChartLine>` 多系列展示各渠道每日送达率
  - 区域 D（失败分布）：`<ChartPie>` 展示失败原因（渠道拒绝/超时/号码无效等）
  - 区域 E（明细表格）：`<a-table>` 展示渠道、发送数、送达数、失败数、送达率、平均延迟
- **响应式断点**：≥1200px 全展开；992-1199px 卡片改为 2×2 网格。
- **首屏内容**：时间筛选 + 4 张渠道卡片 + 趋势图。
- **线框图描述**：

```
┌─────────────────────────────────────────────┐
│ [今日][昨日][近7天][近30天][本月]            │
├────────┬────────┬────────┬────────┤
│ 短信    │ 邮件   │ 站内信 │ Push   │
│ 98.2%  │ 99.1%  │ 100%   │ 95.6% │
│ (仪表) │ (仪表) │ (仪表) │ (仪表)│
├────────────────────────┬────────────────────┤
│ 送达率趋势(折线图)     │ 失败原因(饼图)     │
├─────────────────────────────────────────────┤
│ 渠道明细表格                                  │
└─────────────────────────────────────────────┘
```

## 3. 数据模型与 API 对接
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| GET | `/api/admin/dashboard/notification-delivery` | 查询通知送达率统计 | Operator, Admin |
| GET | `/api/admin/notifications/statistics` | 查询通知投递统计（明细） | Operator, Admin |

- **请求参数**：`start`（DateTime?）、`end`（DateTime?），默认近7天；statistics 端点用 `from`/`to`。
- **响应字段**：`DashboardReportDto`，`ReportType` 为 `NotificationDelivery`，Metrics 含 `sms_rate`/`email_rate`/`inapp_rate`/`push_rate`、`delivery_trend`、`failure_reasons`。statistics 端点返回 `DeliveryStatisticsListDto` 含渠道明细。
- **数据加载策略**：进入页面并行请求 dashboard 与 statistics 端点。
- **缓存策略**：Pinia 缓存键 `notification_delivery_{start}_{end}`，过期 5 分钟。

## 4. 交互流程
- **主流程**：
  1. 进入页面 → 并行加载看板与统计数据 → 渲染卡片、图表、表格
  2. 切换时间预设 → 重新请求
  3. 点击表格行 → 跳转通知记录页（携带渠道筛选）
- **分支流程**：
  - 某渠道送达率 < 95%：仪表盘标红，卡片显示告警
  - 站内信送达率恒为 100%：正常展示
- **跨页面流转**：点击「失败数」跳转通知记录页（筛选状态为失败）。
- **状态机可视化**：无状态字段。

## 5. 组件清单
- **基础组件**：`<a-card>`、`<a-table>`、`<a-tag>`
- **业务组件**：
  - `DashboardCard`（见 shared/components.md §8）— 渠道卡片
  - `DateTimeRangePicker`（见 shared/components.md §4）— 时间筛选
- **图表组件**：
  - `ChartGauge`（见 shared/components.md §7.4）— 各渠道送达率仪表盘，阈值 [95, 99]
  - `ChartLine`（见 shared/components.md §7.1）— 多渠道送达率趋势
  - `ChartPie`（见 shared/components.md §7.2）— 失败原因环形图
- **图标使用**：`WarningOutlined` 告警
- **空状态**：`EmptyState` title="暂无通知数据"

## 6. 视觉规范
- **主色应用**：趋势图各渠道系列用 `#1677FF`/`#52C41A`/`#FAAD14`/`#FF4D4F` 区分。
- **状态色**：送达率 >99% 绿、95-99% 黄、<95% 红。
- **间距**：卡片间距 `24px`，仪表盘高度 `200px`，趋势图 `300px`。
- **字体**：卡片数值 24px semibold，表格 14px。
- **图标尺寸**：告警 16px。

## 7. 异常处理与边界
- **加载态**：首屏 Skeleton；切换时间图表 `<a-spin>`。
- **空数据**：卡片 `--`，图表 EmptyState。
- **错误态**：网络错误 `message.error('加载通知送达率失败')` + 重试。
- **权限控制**：Operator/Admin 可访问。
- **并发与乐观锁**：只读无并发。
- **危险操作确认**：无危险操作。
