# 店铺详情 - 用户 APP

## 1. 页面定位
- **所属端**：用户 APP
- **所属模块**：04-shop 店铺
- **页面类型**：详情页
- **目标用户**：买家（Buyer）
- **核心目标**：买家查看店铺基础信息、资质状态、在售商品列表与店铺评分，进入商品详情或关注店铺。
- **访问入口**：商品详情页店铺入口点击；订单详情店铺点击；搜索结果店铺名点击。
- **实现状态**：🚧 规划中（买家端店铺公开详情端点待补充，现仅卖家/运营端有店铺查询端点）

## 2. 页面布局与信息架构
- **整体布局**：顶部 `van-nav-bar`（返回+店铺名+关注）+ 店铺头部卡片（Logo+名称+简介+关注按钮）+ 评分指标条 + `van-tabs`（在售商品/全部商品/新品）+ 商品 `van-list` 双列瀑布流，无 Tabbar。下拉刷新。
- **关键区域**：
  - 区域 A（店铺头部）：左侧 Logo 64×64 圆角 8px + 右侧店铺名 16px semibold + 简介 12px `#8C8C8C` + 关注按钮（已关注主色填充/未关注主色描边）。
  - 区域 B（评分指标条）：三列等分「描述相符 4.8」「服务态度 4.7」「物流服务 4.6」数值 16px semibold + 标签 12px `#8C8C8C`。
  - 区域 C（资质条）：`van-tag` 展示「营业执照」「品牌授权」等资质状态，点击查看大图。
  - 区域 D（商品 Tabs）：`van-tabs` 「在售商品 / 全部商品 / 新品」+ 排序按钮（综合/销量/价格）。
  - 区域 E（商品列表）：`van-list` 双列瀑布流，复用 `ProductCard`。
- **响应式断点**：375px 双列；≥768px 三列最大 480px。
- **首屏内容**：店铺头部、评分指标、资质条、商品 Tabs 与前 6 个商品卡片。

## 3. 数据模型与 API 对接
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| GET | `/api/products/search` | 查询店铺在售商品（按 shopId 过滤） | Buyer |
| GET | `/api/brands` | 店铺商品品牌聚合 | Buyer |

- **请求参数**：商品搜索 `ProductSearchQueryDto`（keyword、shopId={shopId}、sort、page、pageSize=10）；店铺基础信息走商品详情中的 `shopId` 与 `sellerId` 反查。
- **响应字段**：`ProductSearchResult.items` 含 `id`、`name`、`mainImageUrl`、`price`、`salesCount`、`shopName`、`shopId`；店铺头部信息复用商品域的 `shopId`/`sellerId` 与本地缓存展示。
- **数据加载策略**：进入页面按 `shopId` 加载在售商品首批；切换 Tab/排序重新加载；滚动到底加载下一页。
- **缓存策略**：店铺基础信息缓存 10 分钟（key: `shop_brief_{shopId}`）；商品列表不缓存。

## 4. 交互流程
- **主流程**：
  1. 进入页面读取 `shopId` query → 调用 `GET /api/products/search?shopId=xxx` → 渲染商品列表。
  2. 点击「+关注」→ 切换关注态 → `showToast` 「已关注」/「已取消」。
  3. 点击资质 `van-tag` → `van-image-preview` 弹出资质大图。
  4. 切换 Tab → 重新加载对应商品列表。
  5. 点击商品卡片 → 跳 `/product/:id`。
  6. 滚动到底 → `van-list` 加载下一页。
  7. 下拉刷新 → 重置列表。
- **分支流程**：
  - 店铺暂停营业：头部显示「暂停营业」橙色标签，商品列表正常展示但加购时提示。
  - 无在售商品：`EmptyState title="店铺暂无在售商品"`。
  - 关注失败：网络错误回滚关注态并提示。
- **跨页面流转**：商品卡片跳商品详情页；返回时保留列表位置与筛选状态。
- **状态机可视化**：加载中(skeleton) → 在售(列表) / 暂停营业(警示+列表) / 无商品(空状态)。

## 5. 组件清单
- **基础组件**：`van-nav-bar`、`van-image`、`van-button`、`van-tag`、`van-tabs`、`van-list`、`van-pull-refresh`、`van-image-preview`、`van-skeleton`。
- **业务组件**：`ProductCard` 自研商品卡片；`ShopHeader` 自研店铺头部；`RatingBar` 自研评分展示；`EmptyState`（见 shared/components.md §5）；`IdempotencyButton`（见 shared/components.md §2）— 关注按钮。
- **图表组件**：无。
- **图标使用**：返回 `arrow-left`；关注 `plus`/`success`；资质 `certificate`。
- **空状态**：商品列表空使用 `EmptyState title="店铺暂无在售商品" ctaText="去逛逛"`。

## 6. 视觉规范
- **主色应用**：已关注按钮主色填充 `#1677FF`；未关注主色描边；Tab 激活态主色；评分数值主色。
- **状态色**：暂停营业 `#FAAD14`；资质标签 `#52C41A`；价格 `#FF4D4F`。
- **间距**：头部卡片内边距 12px；评分条上下 12px；商品卡片间距 8px；Tab 高 44px。
- **字体**：店铺名 16px semibold `#000000D9`；简介 12px `#8C8C8C`；评分数值 16px semibold `#1677FF`；评分标签 12px `#8C8C8C`；商品价格 16px semibold `#FF4D4F`。
- **图标尺寸**：Logo 64×64；返回 20px；关注图标 16px。

## 7. 异常处理与边界
- **加载态**：首屏 `van-skeleton` 模拟头部+评分+商品布局；分页 `van-list` loading。
- **空数据**：商品列表空 `EmptyState` + CTA。
- **错误态**：接口失败全屏错误 + 重试。
- **权限控制**：Buyer 可见；关注操作需登录态。
- **并发与乐观锁**：切换 Tab/排序取消上一个请求；关注按钮 300ms 防抖，关注态切换采用乐观更新失败回滚。
- **危险操作确认**：取消关注 `showConfirmDialog` 二次确认（避免误触流失关注）。
