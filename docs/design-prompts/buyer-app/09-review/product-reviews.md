# 商品评价列表 - 用户 APP

## 1. 页面定位
- **所属端**：用户 APP
- **所属模块**：09-review 评价
- **页面类型**：列表页（嵌入页）
- **目标用户**：买家（Buyer）/ 游客
- **核心目标**：在商品详情页内嵌展示该 SPU 的已通过评价列表，支持分页浏览、查看图片与卖家回复，辅助购买决策。
- **访问入口**：商品详情页评价区「查看全部 N 条评价」入口；评价区直接内嵌首屏 3 条预览。
- **实现状态**：✅ 已实现

## 2. 页面布局与信息架构
- **整体布局**：顶部 `van-nav-bar`（返回 + 标题「商品评价 N 条」）+ 评分概览卡 + `van-list` 评价卡片无限滚动，无 Tabbar。
- **关键区域**：
  - 区域 A（评分概览卡）：左侧大字展示评分均值（如 4.8），右侧 5 星分布柱状条（5★~1★ 占比），下方「好评率 96%」。
  - 区域 B（标签筛选）：`van-tabs` 横向滑动标签（全部/有图/好评/中评/差评/有追评），切换重置列表。
  - 区域 C（评价卡片）：每张卡片展示用户头像（匿名则默认头像）+ 昵称 + 评分 + 规格SKU + 评价内容 + 图片缩略图 + 卖家回复 + 时间；含追评的卡片折叠展示「买家追评」。
  - 区域 D（空状态）：`van-empty`「暂无评价」+ 「去购买」CTA。
- **响应式断点**：375px 基准；≥768px 居中最大 480px。
- **首屏内容**：评分概览、标签筛选、首屏 20 条评价卡片。

## 3. 数据模型与 API 对接
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| GET | `/api/products/{spuId}/reviews` | 按 SPU 分页查询已通过评价 | 公开（无需鉴权） |

- **请求参数**：`spuId` 路径参数；`page` 从 1 起；`pageSize` 默认 20；服务端仅返回 `Approved` 状态评价。
- **响应字段**：`{ items, total, page, pageSize }`；item 含 `reviewId`、`userId`、`userName`（匿名时为「匿名用户」）、`userAvatar`、`rating`、`skuName`、`content`、`images`、`sellerReply`、`sellerReplyAt`、`appendContent`、`appendAt`、`createdAt`。
- **数据加载策略**：进入页面带 `spuId` 调用 `GET /api/products/{spuId}/reviews?page=1`；`van-list` 无限滚动追加；下拉刷新。
- **缓存策略**：列表不缓存；评分概览可缓存 5 分钟（基于 `spuId`）。

## 4. 交互流程
- **主流程**：
  1. 商品详情页评价区点击「查看全部 N 条」→ 跳本页带 `spuId` → `GET /api/products/{spuId}/reviews?page=1` → 渲染评分概览 + 评价卡片。
  2. 切换标签筛选（如有图）→ 前端过滤当前已加载数据 + 标记需服务端过滤（仅 `hasImage` 客户端可计算，其余如「好评」`rating>=4` 客户端过滤）→ 重置列表。
  3. 滚动到底部 → `van-list` load → 追加下一页。
  4. 点击图片缩略图 → `van-image-preview` 全屏预览，支持滑动切换。
  5. 点击「查看追评」→ 展开追评内容 + 追评时间。
  6. 点击用户头像/昵称 → 无操作（仅展示）。
- **分支流程**：
  - 空列表：`van-empty`「暂无评价」+ 「去购买」CTA 跳商品详情页。
  - 接口失败：`showToast` 「加载失败」+ 重试按钮。
  - 游客访问：允许查看，不展示「写评价」入口。
- **跨页面流转**：返回商品详情页；无跳转其他页面。
- **状态机可视化**：无（仅展示已通过评价）。

## 5. 组件清单
- **基础组件**：`van-nav-bar`、`van-list`、`van-pull-refresh`、`van-image`（lazy-load + preview）、`van-rate`（只读）、`van-tabs`、`van-tab`、`van-empty`、`van-skeleton`、`van-toast`（showToast）、`van-image-preview`（showImagePreview）。
- **业务组件**：`RatingOverviewCard` 评分概览卡（含均值、分布柱、好评率）；`ProductReviewCard` 商品评价卡片（含用户、评分、规格、内容、图片、追评、卖家回复）；`ReviewTagFilter` 标签筛选；`EmptyState`（见 shared/components.md §5）。
- **图表组件**：无（评分分布用 CSS 实现柱状条）。
- **图标使用**：返回 `arrow-left`；图片 `photo-o`；追评展开 `arrow-down`/`arrow-up`。
- **空状态**：`van-empty`「暂无评价」+ 「去购买」CTA 跳商品详情页。

## 6. 视觉规范
- **主色应用**：评分均值数字主色 `#1677FF`；标签激活态主色；5 星激活态主色。
- **状态色**：5★ `#52C41A`；3-4★ `#FAAD14`；1-2★ `#FF4D4F`；好评率文字 `#52C41A`。
- **间距**：评分概览卡内边距 16px；卡片间距 12px；卡片内边距 12px；图片缩略图 72×72px。
- **字体**：评分均值 30px semibold `#1677FF`；好评率 12px `#52C41A`；用户昵称 14px medium `#000000D9`；评价内容 14px `#595959`；规格 12px `#8C8C8C`；时间 12px `#8C8C8C`；卖家回复 13px `#595959`（背景 `#FAFAFA`）。
- **图标尺寸**：返回 20px；评分星 16px；图片 20px。

## 7. 异常处理与边界
- **加载态**：首屏 `van-skeleton` 模拟评分概览 + 3 张评价卡片。
- **空数据**：`van-empty`「暂无评价」+ 「去购买」CTA 跳商品详情页。
- **错误态**：接口失败 `showToast` 「加载失败」+ 重试按钮；`van-pull-refresh` 下拉刷新。
- **权限控制**：公开页面，游客可访问；不展示「写评价」入口（仅订单详情已完成订单可写）。
- **并发与乐观锁**：不涉及（只读列表）。
- **危险操作确认**：不涉及。
