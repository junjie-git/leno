# 搜索结果 - 用户 APP

## 1. 页面定位
- **所属端**：用户 APP
- **所属模块**：03-catalog 商品目录
- **页面类型**：列表页
- **目标用户**：买家（Buyer）
- **核心目标**：买家查看关键词搜索/分类筛选后的商品列表，按价格、销量排序，点击进入商品详情。
- **访问入口**：搜索页跳转；分类页二级分类点击；首页搜索快捷入口。
- **实现状态**：✅ 已实现

## 2. 页面布局与信息架构
- **整体布局**：顶部搜索栏（返回+关键词+搜索按钮）+ 筛选排序条 + 商品 `van-list` 双列瀑布流，无 Tabbar。下拉刷新。
- **关键区域**：
  - 区域 A（搜索栏）：返回箭头 + `van-search` 预填关键词可再次编辑 + 「搜索」按钮。
  - 区域 B（筛选排序条）：`van-tabs` 或固定按钮组「综合 / 销量 / 价格（升降切换） / 筛选」，最右「筛选」点击弹出 `van-popup` 侧滑筛选面板。
  - 区域 C（商品列表）：`van-list` 双列瀑布流，每卡含商品图、名称、价格、销量、店铺名。
  - 区域 D（筛选面板）：`van-popup position="right"` 宽 80%，含分类、品牌、价格区间筛选 + 重置/确定按钮。
- **响应式断点**：375px 双列；≥768px 三列最大 480px。
- **首屏内容**：搜索栏预填、筛选排序条、前 6 个商品卡片。
- **线框图描述**：
```
┌──────────────────┐
│ ← [iPhone 15] 搜索│
├──────────────────┤
│ 综合 销量 价格↑ 筛选│
├──────────────────┤
│ [商品] [商品]    │
│ [商品] [商品]    │
│ [商品] [商品]    │
│ ... 加载中       │
└──────────────────┘
```

## 3. 数据模型与 API 对接
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| GET | `/api/products/search` | 关键词 + 筛选搜索商品 | Buyer |
| GET | `/api/brands` | 筛选面板品牌列表 | Buyer |

- **请求参数**：`ProductSearchQueryDto` 含 `keyword`、`categoryId`、`brandId`、`minPrice`、`maxPrice`、`sort`（hot/priceAsc/priceDesc/sales）、`page`、`pageSize=10`。
- **响应字段**：`ProductSearchResult` 含 `items`（id、name、mainImageUrl、price、salesCount、shopName、shopId）、`total`、`aggregations`（可选聚合）。
- **数据加载策略**：进入页面按 query 加载首批；切换排序/筛选重新加载；滚动到底加载下一页。
- **缓存策略**：不缓存（实时性要求）；筛选状态暂存内存防页面回退丢失。

## 4. 交互流程
- **主流程**：
  1. 进入页面读取 `keyword`/`categoryId` query → 调用搜索 → 渲染列表。
  2. 点击「销量」/「价格」→ 切换 sort → 重新加载列表。
  3. 点击「筛选」→ 侧滑面板 → 选择分类/品牌/价格区间 → 点击「确定」→ 重新加载。
  4. 点击商品卡片 → 跳 `/product/:id`。
  5. 滚动到底 → `van-list` 加载下一页。
  6. 下拉刷新 → 重置列表。
- **分支流程**：
  - 无结果：`EmptyState title="未找到相关商品" ctaText="清空筛选条件"`。
  - 价格升序/降序切换图标箭头方向。
- **跨页面流转**：商品卡片跳详情页。
- **状态机可视化**：加载中 → 已加载(列表) / 无结果(空状态)。

## 5. 组件清单
- **基础组件**：`van-search`、`van-tabs`/`van-button`、`van-list`、`van-pull-refresh`、`van-popup`、`van-tree-select`（分类）、`van-checkbox-group`（品牌）、`van-field`（价格）、`van-image`、`van-skeleton`。
- **业务组件**：`ProductCard` 自研商品卡片；`EmptyState`（见 shared/components.md §5）。
- **图表组件**：无。
- **图标使用**：返回 `arrow-left`；价格升降 `arrow-up`/`arrow-down`；筛选 `filter-o`。
- **空状态**：`EmptyState title="未找到相关商品" ctaText="清空筛选条件"`。

## 6. 视觉规范
- **主色应用**：选中排序标签主色 `#1677FF`；筛选面板确定按钮主色。
- **状态色**：价格 `#FF4D4F`；销量 `#8C8C8C`；筛选激活 `#1677FF`。
- **间距**：排序条高 40px；商品卡片间距 8px；卡片内边距 8px。
- **字体**：商品名 14px `#000000D9`（2 行省略）；价格 16px semibold `#FF4D4F`；销量 12px `#8C8C8C`；店铺名 12px `#595959`。
- **图标尺寸**：返回 20px；升降箭头 16px。

## 7. 异常处理与边界
- **加载态**：首屏 `van-skeleton` 6 卡片占位；分页 `van-list` loading。
- **空数据**：`EmptyState` + 清空筛选 CTA。
- **错误态**：接口失败全屏错误 + 重试。
- **权限控制**：Buyer 可见。
- **并发与乐观锁**：切换排序/筛选取消上一个请求；`van-list` finished 状态防重复加载。
- **危险操作确认**：不涉及。

## 8. 验收要点
- [ ] 排序切换正确刷新列表，价格升降序图标切换。
- [ ] 筛选面板侧滑，确定后携带筛选参数重新加载。
- [ ] `van-list` 上拉加载、下拉刷新正常。
- [ ] 无结果时 `EmptyState` + 清空筛选 CTA。
- [ ] 商品卡片跳详情页携带 id。
- **性能要求**：搜索响应 < 800ms；分页 < 600ms；图片懒加载；切换请求取消旧请求。
- **可访问性**：排序标签 `aria-selected`；筛选面板 `role="dialog"`；商品卡片 `aria-label`。
