# 搜索 - 用户 APP

## 1. 页面定位
- **所属端**：用户 APP
- **所属模块**：03-catalog 商品目录
- **页面类型**：流程页
- **目标用户**：买家（Buyer）
- **核心目标**：买家输入搜索关键词，查看搜索历史与热搜词，点击搜索或联想词进入搜索结果页。
- **访问入口**：首页搜索栏；分类页搜索栏；商品详情页顶部搜索。
- **实现状态**：✅ 已实现（搜索执行复用 `/api/products/search`）

## 2. 页面布局与信息架构
- **整体布局**：顶部搜索栏（返回+输入框+搜索按钮）+ 内容区（未输入时显示搜索历史与热搜词，输入时显示联想词列表），无 Tabbar。
- **关键区域**：
  - 区域 A（搜索栏）：左侧返回箭头，`van-search` 自动聚焦，右侧「搜索」文字按钮主色。
  - 区域 B（搜索历史区，未输入时）：标题「搜索历史」+ 「清空」图标 + `van-tag` 历史词横排（点击触发搜索）。
  - 区域 C（热搜词区，未输入时）：标题「热门搜索」+ 编号列表（前 3 红色编号，其余灰色）。
  - 区域 D（联想词区，输入时）：`van-cell` 列表，每项含关键词与匹配高亮，点击直接搜索。
- **响应式断点**：375px 基准；≥768px 居中最大 480px。
- **首屏内容**：搜索栏自动聚焦、搜索历史、热搜词列表。
- **线框图描述**：

## 3. 数据模型与 API 对接
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| GET | `/api/products/search` | 联想词触发时预查询（可选） | Buyer |

- **请求参数**：联想 `ProductSearchQueryDto` 含 `keyword`、`page=1`、`pageSize=5`；热搜词无后端端点，前端本地维护或由字典配置。
- **响应字段**：联想返回 `ProductSearchResult.items` 含 `name`，前端提取匹配关键词。
- **数据加载策略**：进入页面无网络请求，从 localStorage 读取搜索历史；输入时 300ms 防抖触发联想查询。
- **缓存策略**：搜索历史存 localStorage（key: `search_history`，最多 10 条，去重，最新在前）；热搜词可由 `GET /api/dictionaries/{code}` 配置（code: `hot_search_keywords`）。

## 4. 交互流程
- **主流程**：
  1. 进入页面 → 搜索框自动聚焦弹出键盘 → 显示搜索历史与热搜词。
  2. 输入关键词 → 300ms 防抖 → 调用 `GET /api/products/search?keyword=xxx&pageSize=5` → 显示联想词列表。
  3. 点击联想词 / 历史词 / 热搜词 → 跳 `/search/results?keyword=xxx` → 将词加入搜索历史。
  4. 点击「搜索」按钮或键盘 Enter → 同上跳转。
- **分支流程**：
  - 输入为空：不显示联想，回到历史与热搜。
  - 联想无结果：显示「无匹配，按回车搜索全部」。
  - 点击「清空」：`showConfirmDialog` 确认清空搜索历史。
- **跨页面流转**：跳 `/search/results` 携带 `keyword`。
- **状态机可视化**：默认(历史+热搜) → 输入中(联想) → 已搜索(跳转)。

## 5. 组件清单
- **基础组件**：`van-search`、`van-tag`、`van-cell`、`van-cell-group`、`van-icon`、`van-dialog`、`van-toast`。
- **业务组件**：无额外业务组件。
- **图表组件**：无。
- **图标使用**：返回 `arrow-left`；清空 `delete-o`；热搜编号本地渲染。
- **空状态**：搜索历史为空隐藏历史区；联想无结果显示提示行。

## 6. 视觉规范
- **主色应用**：搜索按钮、`van-tag` 边框主色 `#1677FF`；热搜前 3 编号 `#FF4D4F`。
- **状态色**：联想匹配高亮 `#1677FF`；热搜 4+ 编号 `#8C8C8C`。
- **间距**：搜索栏 padding 8px；历史/热搜区 padding 12px；`van-tag` 间距 8px。
- **字体**：标题 14px medium `#595959`；热搜词 14px `#000000D9`；联想词 14px。
- **图标尺寸**：返回 20px；清空 16px。

## 7. 异常处理与边界
- **加载态**：联想查询时显示 `van-loading` 小图标在搜索框右侧。
- **空数据**：历史空隐藏；联想无结果提示行。
- **错误态**：联想查询失败静默处理，不影响输入。
- **权限控制**：Buyer 可见。
- **并发与乐观锁**：300ms 防抖避免频繁请求；新请求取消上一个未完成请求。
- **危险操作确认**：清空历史 `showConfirmDialog` 二次确认。

- [ ] 输入 300ms 防抖触发联想，新请求取消旧请求。

- [ ] 清空历史二次确认。

- **可访问性**：搜索框 `aria-label`；历史标签可键盘操作；Enter 触发搜索。
