# 分类导航 - 用户 APP

## 1. 页面定位
- **所属端**：用户 APP
- **所属模块**：03-catalog 商品目录
- **页面类型**：列表页
- **目标用户**：买家（Buyer）
- **核心目标**：买家通过左侧分类树与右侧二级分类商品列表快速定位目标商品。
- **访问入口**：底部 Tabbar「分类」；首页分类快捷入口。
- **实现状态**：✅ 已实现

## 2. 页面布局与信息架构
- **整体布局**：顶部搜索栏 + 左右分栏（左侧一级分类 90px 宽，右侧二级分类内容区），底部 Tabbar。左侧滚动选中态高亮，右侧随选中切换内容。
- **关键区域**：
  - 区域 A（搜索栏）：固定顶部 `van-search` 占位「搜索商品」点击跳 `/search`。
  - 区域 B（一级分类侧栏）：`van-sidebar` 90px 宽，垂直滚动，选中项主色文字 + 左侧 3px 主色竖条 + 白底。
  - 区域 C（二级分类区）：右侧内容区，顶部为二级分类 `van-grid`（2 列图标入口），下方为该一级分类下推荐商品 `van-list` 双列瀑布流。
- **响应式断点**：375px 左栏 90px；≥768px 左栏 120px，右栏最大 360px。
- **首屏内容**：搜索栏、第一个一级分类高亮、其下二级分类网格与商品列表。
- **线框图描述**：

## 3. 数据模型与 API 对接
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| GET | `/api/categories/tree` | 获取完整分类树（含层级） | Buyer |
| GET | `/api/products/search` | 按分类查询商品列表 | Buyer |

- **请求参数**：`tree` 无参；商品搜索 `ProductSearchQueryDto` 含 `categoryId`、`page`、`pageSize=10`、`sort=hot`。
- **响应字段**：`CategoryDto` 含 `id`、`name`、`iconUrl`、`children`（二级分类数组）；`ProductSearchResult` 同首页。
- **数据加载策略**：进入页面加载分类树，默认选中第一个一级分类，按其 id 加载商品；切换一级分类时重新加载商品。
- **缓存策略**：分类树缓存 Pinia 1 小时（key: `catalog_tree`），所有页面共享。

## 4. 交互流程
- **主流程**：
  1. 进入页面 → 加载分类树 → 默认选中第一个一级分类 → 调用 `GET /api/products/search?categoryId=xxx` 加载商品。
  2. 点击左侧一级分类 → 切换选中态 → 重新加载右侧商品。
  3. 点击二级分类网格 → 跳 `/search/results?categoryId=xxx`。
  4. 点击商品卡片 → 跳 `/product/:id`。
  5. 右侧滚动到底 → `van-list` 加载下一页。
- **分支流程**：
  - 一级分类无二级：直接展示商品列表。
  - 商品列表为空：`EmptyState title="该分类下暂无商品"`。
- **跨页面流转**：商品卡片跳详情页；二级分类跳搜索结果页。
- **状态机可视化**：加载分类树 → 选中一级 → 加载商品 → 滚动加载更多。

## 5. 组件清单
- **基础组件**：`van-search`、`van-sidebar`、`van-sidebar-item`、`van-grid`、`van-grid-item`、`van-list`、`van-image`、`van-skeleton`。
- **业务组件**：`ProductCard` 自研商品卡片；`EmptyState`（见 shared/components.md §5）。
- **图表组件**：无。
- **图标使用**：分类图标来自 `CategoryDto.iconUrl`；搜索 `search`。
- **空状态**：`EmptyState title="该分类下暂无商品" ctaText="去逛逛"`。

## 6. 视觉规范
- **主色应用**：选中一级分类文字与竖条主色 `#1677FF`；二级分类图标背景浅蓝 `#E6F4FF`。
- **状态色**：未选中文字 `#595959`；选中背景 `#FFFFFF`；左栏背景 `#FAFAFA`。
- **间距**：左栏宽 90px；右栏 padding 12px；网格项间距 12px；商品卡片间距 8px。
- **字体**：一级分类 14px medium；二级分类名 12px `#595959`；商品名 14px `#000000D9`；价格 16px semibold `#FF4D4F`。
- **图标尺寸**：二级分类图标 48px；商品图 100×100。

## 7. 异常处理与边界
- **加载态**：分类树与商品 `van-skeleton` 占位。
- **空数据**：商品空 `EmptyState`。
- **错误态**：分类树加载失败全屏错误 + 重试；商品加载失败局部重试。
- **权限控制**：Buyer 可见。
- **并发与乐观锁**：切换一级分类时取消上一个未完成请求，避免数据错乱。
- **危险操作确认**：不涉及。

- **可访问性**：分类项 `aria-current`；商品卡片 `aria-label`；左右栏支持键盘上下导航。
