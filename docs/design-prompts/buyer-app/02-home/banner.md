# 轮播 Banner - 用户 APP

## 1. 页面定位
- **所属端**：用户 APP
- **所属模块**：02-home 首页
- **页面类型**：嵌入页
- **目标用户**：买家（Buyer）
- **核心目标**：在首页顶部展示运营推广 Banner 轮播，点击跳转对应活动、商品或外链，承担营销导流职责。
- **访问入口**：嵌入首页推荐流顶部区域；独立预览页 `/banner`。
- **实现状态**：➕ 补充功能（Banner 数据复用公告/活动端点，独立轮播组件）

## 2. 页面布局与信息架构
- **整体布局**：作为嵌入组件，高度 160px，圆角 12px，左右边距 12px，自动播放 3s 切换，底部居中指示器。
- **关键区域**：
  - 区域 A（图片区）：`van-swipe-item` 全填充 `van-image`（lazy-load，圆角 12px）。
  - 区域 B（文案叠层，可选）：左下角半透明遮罩 + 标题文案 16px 白色。
  - 区域 C（指示器）：底部居中圆点，激活态主色 `#1677FF`，非激活半透明白。
- **响应式断点**：375px 高 160px；≥768px 高 200px 最大宽 480px。
- **首屏内容**：第一张 Banner 图与指示器。
- **线框图描述**：
```
┌──────────────────┐
│ ╭──────────────╮ │
│ │              │ │
│ │  Banner 图片 │ │
│ │  标题叠层    │ │
│ │      ● ○ ○   │ │
│ ╰──────────────╯ │
└──────────────────┘
```

## 3. 数据模型与 API 对接
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| GET | `/api/announcements` | 获取已发布公告（含 Banner 类型） | Buyer |

- **请求参数**：`page=1`、`pageSize=10`；前端按 `type === 'Banner'` 过滤。
- **响应字段**：`AnnouncementListResultDto.items` 含 `id`、`title`、`type`、`content`、`imageUrl`、`linkUrl`、`linkType`（activity/product/url）。
- **数据加载策略**：随首页加载一并请求；独立预览页进入时加载。
- **缓存策略**：Banner 列表缓存 Pinia 5 分钟（key: `home_banners`），避免重复请求。

## 4. 交互流程
- **主流程**：
  1. 首页加载 → 请求公告端点 → 过滤 Banner 类型 → 渲染 `van-swipe`。
  2. 自动播放 3s 切换；用户手动滑动后暂停自动播放 5s 再恢复。
  3. 点击 Banner → 按 `linkType` 跳转：activity 跳秒杀/促销页，product 跳 `/product/:id`，url 跳外链。
- **分支流程**：
  - Banner 为空：隐藏整个 Banner 区域。
  - 仅 1 张：不显示指示器，不自动播放。
  - 图片加载失败：显示占位图 `van-image` error 占位。
- **跨页面流转**：点击跳转目标页，携带 `linkUrl` 解析的参数。
- **状态机可视化**：加载中(placeholder) → 加载完成(轮播) / 加载失败(隐藏)。

## 5. 组件清单
- **基础组件**：`van-swipe`、`van-swipe-item`、`van-image`、`van-skeleton`。
- **业务组件**：无额外业务组件，作为 `HomeBanner` 自研组件封装。
- **图表组件**：无。
- **图标使用**：无图标。
- **空状态**：无 Banner 时隐藏区域。

## 6. 视觉规范
- **主色应用**：指示器激活态主色 `#1677FF`。
- **状态色**：文案遮罩半透明黑 `#00000066`；占位图 `#F5F5F5`。
- **间距**：左右边距 12px；圆角 12px（`radius/lg`）。
- **字体**：标题叠层 16px semibold 白色。
- **图标尺寸**：无。

## 7. 异常处理与边界
- **加载态**：`van-skeleton` 占位 160px 高度。
- **空数据**：隐藏区域，不报错。
- **错误态**：图片加载失败 `van-image` 显示占位图；接口失败隐藏区域。
- **权限控制**：随首页权限，Buyer 可见。
- **并发与乐观锁**：不涉及。
- **危险操作确认**：不涉及。

## 8. 验收要点
- [ ] 自动播放 3s 切换，手动滑动后暂停 5s。
- [ ] 指示器正确显示当前位置。
- [ ] 点击跳转按 linkType 正确路由。
- [ ] 单张时不显示指示器与自动播放。
- [ ] 图片懒加载，加载失败有占位。
- **性能要求**：首张 Banner < 500ms 加载；切换动画 300ms 流畅。
- **可访问性**：Banner 有 `alt` 描述；指示器 `aria-label`；支持键盘左右切换。
