# 秒杀入口 - 用户 APP

## 1. 页面定位
- **所属端**：用户 APP
- **所属模块**：02-home 首页
- **页面类型**：嵌入页
- **目标用户**：买家（Buyer）
- **核心目标**：在首页展示当前进行中的秒杀活动横滑卡片，含实时倒计时与秒杀价，引导买家进入秒杀下单页。
- **访问入口**：嵌入首页推荐流秒杀区域；「查看更多」跳秒杀活动聚合列表。
- **实现状态**：✅ 已实现

## 2. 页面布局与信息架构
- **整体布局**：区域标题栏（左「限时秒杀」+ 红色闪电图标，右「查看更多 >」）+ 横滑 `van-swipe` 卡片组，每屏显示 3.5 张卡片露边提示可滑。
- **关键区域**：
  - 区域 A（标题栏）：左侧标题 16px semibold + 闪电图标 `#FF4D4F`；右侧「查看更多」14px `#8C8C8C` + 箭头。
  - 区域 B（倒计时条）：标题下方红色条带显示「距结束 HH:MM:SS」白字红底。
  - 区域 C（卡片组）：`van-swipe` 每项含商品图（80×80 圆角 8px）、商品名（1 行省略）、秒杀价（红 16px semibold）、原价（划线 12px 灰）。
- **响应式断点**：375px 每屏 3.5 张；≥768px 每屏 5.5 张。
- **首屏内容**：标题栏、倒计时条、前 3 张秒杀卡片。
- **线框图描述**：
```
┌──────────────────┐
│ ⚡限时秒杀 查看更多>│
│ 距结束 02:15:30  │ 红底白字
├──────────────────┤
│ [图][图][图][→]  │
│ 名称 名称 名称   │
│ ¥99 ¥99 ¥99      │
│ ¥199 ¥199 ¥199   │
└──────────────────┘
```

## 3. 数据模型与 API 对接
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| GET | `/api/seckill/activities` | 查询进行中秒杀活动列表 | Buyer |
| GET | `/api/seckill/activities/{activityId}` | 秒杀活动详情（含 Redis 实时库存） | Buyer |

- **请求参数**：`GetActiveAsync` 无参，返回所有进行中活动。
- **响应字段**：`SeckillActivityDto` 含 `id`、`name`、`startTime`、`endTime`、`seckillPrice`、`originalPrice`、`imageUrl`、`stock`（实时库存）、`limitPerUser`。
- **数据加载策略**：随首页加载一并请求；倒计时前端基于 `endTime` 与本地时间计算，每秒刷新。
- **缓存策略**：活动列表缓存 30 秒（key: `home_seckill`）；倒计时纯前端计算不重复请求。

## 4. 交互流程
- **主流程**：
  1. 首页加载 → 请求 `GET /api/seckill/activities` → 渲染标题栏与卡片组。
  2. 倒计时每秒刷新；活动 `endTime` 到达后从列表移除该卡片。
  3. 点击卡片 → 跳 `/seckill/order/:activityId`。
  4. 点击「查看更多」→ 跳秒杀活动聚合列表（扩展页）。
- **分支流程**：
  - 无进行中活动：隐藏整个秒杀区域。
  - 库存为 0：卡片显示「已抢光」灰色遮罩，不可点击。
  - 倒计时结束：移除卡片，若全部结束隐藏区域。
- **跨页面流转**：点击卡片跳秒杀下单页携带 `activityId`。
- **状态机可视化**：进行中(倒计时) → 已结束(移除) / 已抢光(置灰)。

## 5. 组件清单
- **基础组件**：`van-swipe`、`van-swipe-item`、`van-image`、`van-skeleton`。
- **业务组件**：`SeckillCard` 自研秒杀卡片；`Countdown` 自研倒计时组件（HH:MM:SS）。
- **图表组件**：无。
- **图标使用**：闪电图标本地 SVG `#FF4D4F`；箭头 `arrow`。
- **空状态**：无活动时隐藏区域。

## 6. 视觉规范
- **主色应用**：秒杀价 `#FF4D4F`；倒计时条红底 `#FF4D4F` 白字。
- **状态色**：已抢光 `#8C8C8C` 灰色遮罩；原价划线 `#8C8C8C`。
- **间距**：区域上下 12px；卡片间距 8px；卡片内边距 8px。
- **字体**：标题 16px semibold；倒计时 14px semibold 白色；商品名 12px `#595959`；秒杀价 16px semibold `#FF4D4F`。
- **图标尺寸**：闪电 16px；商品图 80×80。

## 7. 异常处理与边界
- **加载态**：`van-skeleton` 占位 3 张卡片。
- **空数据**：隐藏区域。
- **错误态**：接口失败隐藏区域，不影响首页其他区域。
- **权限控制**：Buyer 可见；未登录跳登录。
- **并发与乐观锁**：倒计时纯前端计算，不发起请求；库存显示静态（下单时再校验）。
- **危险操作确认**：不涉及。

## 8. 验收要点
- [ ] 倒计时每秒刷新，结束自动移除卡片。
- [ ] 卡片横滑流畅，露边提示可滑。
- [ ] 库存为 0 显示「已抢光」置灰。
- [ ] 点击卡片跳秒杀下单页携带 activityId。
- [ ] 无活动时隐藏整个区域。
- **性能要求**：活动列表加载 < 800ms；倒计时定时器在页面销毁时清除。
- **可访问性**：卡片有 `aria-label` 含商品名与价格；倒计时 `aria-live="off"` 避免频繁播报。
