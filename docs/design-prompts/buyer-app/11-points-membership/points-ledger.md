# 积分流水 - 用户 APP

## 1. 页面定位
- **所属端**：用户 APP
- **所属模块**：11-points-membership 积分会员
- **页面类型**：列表页
- **目标用户**：买家（Buyer）
- **核心目标**：买家分页查询积分流水明细，按类型（获取/消耗）与来源（订单/签到/兑换/任务）筛选，了解积分变动历史。
- **访问入口**：积分账户页「流水明细」入口；积分账户页「查看全部」。
- **实现状态**：✅ 已实现

## 2. 页面布局与信息架构
- **整体布局**：顶部 `van-nav-bar`（返回 + 标题「积分流水」）+ 余额汇总条 + `van-tabs` 类型筛选（全部/获取/消耗）+ `van-list` 流水卡片无限滚动，无 Tabbar。
- **关键区域**：
  - 区域 A（余额汇总条）：展示当前可用积分余额「可用 2,860」+ 「≈ ¥28.60」换算提示。
  - 区域 B（类型筛选 Tab）：`van-tabs` 3 个标签（全部/获取/消耗），切换后前端过滤已加载数据。
  - 区域 C（流水卡片）：每张卡片展示来源图标 + 类型标签 + 描述 + 金额（+绿色/-红色）+ 变动后余额 + 时间；按日期分组（今日/昨日/更早）。
  - 区域 D（空状态）：`van-empty`「暂无流水」+ 「去赚积分」CTA。

- **首屏内容**：导航栏、余额汇总条、类型筛选 Tab、流水卡片首屏。

## 3. 数据模型与 API 对接
- **服务归属**：Points 域（旧域 PointsMembership 双轨兜底，端点路径不变）
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| GET | `/api/points/ledger` | 分页查询积分流水 | Buyer |
| GET | `/api/points/account` | 查询积分账户余额 | Buyer |

- **请求参数**：`GET /api/points/ledger?page={page}&pageSize=20`；服务端按用户筛选，不支持类型过滤（前端过滤）；账户查询无参数。
- **响应字段**：流水 `PointsLedgerDto` 含 `ledgerId`、`type`（Earn/Spend）、`source`（Order/CheckIn/Exchange/Task/AdminAward）、`amount`、`balanceAfter`、`description`、`createdAt`；账户 `PointsAccountDto` 含 `balance`。
- **数据加载策略**：进入页面并行调用账户与流水接口；`van-list` 无限滚动，每页 20 条；切换 Tab 前端过滤已加载数据；下拉刷新。
- **缓存策略**：账户缓存 30s；流水不缓存。

## 4. 交互流程
- **主流程**：
  1. 进入页面 → 并行调用 `GET /api/points/account` 与 `GET /api/points/ledger?page=1` → 渲染余额汇总条 + 流水卡片（按日期分组）。
  2. 切换类型 Tab → 前端过滤已加载数据（Earn/Spend）→ 重置列表展示。
  3. 滚动到底部 → `van-list` load → 追加下一页。
  4. 下拉刷新 → 重置列表重新拉取。
- **分支流程**：
  - 空列表：`van-empty`「暂无流水」+ 「去赚积分」CTA 跳任务中心。
  - 接口失败：`showToast` 「加载失败」+ 重试按钮。
- **跨页面流转**：「去赚积分」跳任务中心页；无其他跳转。
- **状态机可视化**：无（只读列表）。

- **空状态**：`van-empty`「暂无流水」+ 「去赚积分」CTA 跳任务中心。

## 6. 视觉规范
- **主色应用**：余额数字主色 `#1677FF`；Tab 激活态主色；获取类型标签主色边框。
- **状态色**：获取积分 `+` 前缀 `#52C41A`；消耗积分 `-` 前缀 `#FF4D4F`；变动后余额 `#8C8C8C`。
- **间距**：余额汇总条内边距 16px；卡片间距 8px；卡片内边距 12px；日期分组标题间距 12px。
- **字体**：余额数字 20px semibold `#1677FF`；换算 12px `#8C8C8C`；日期分组标题 12px medium `#8C8C8C`；流水描述 14px `#000000D9`；金额 16px semibold；变动后余额 12px `#8C8C8C`；时间 12px `#8C8C8C`。
- **图标尺寸**：返回 20px；流水来源图标 20px。

## 7. 异常处理与边界
- **加载态**：首屏 `van-skeleton` 模拟余额汇总条 + 5 张流水卡片。
- **空数据**：`van-empty`「暂无流水」+ 「去赚积分」CTA 跳任务中心。
- **错误态**：接口失败 `showToast` 「加载失败」+ 重试按钮；`van-pull-refresh` 下拉刷新。
- **权限控制**：Buyer 可见；未登录跳 `/login?redirect=/points/ledger`；只能查看本人流水。
- **并发与乐观锁**：不涉及（只读列表）。
- **危险操作确认**：不涉及。
