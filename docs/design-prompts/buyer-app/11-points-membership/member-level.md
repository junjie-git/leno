# 会员等级 - 用户 APP

## 1. 页面定位
- **所属端**：用户 APP
- **所属模块**：11-points-membership 积分会员
- **页面类型**：详情页
- **目标用户**：买家（Buyer）
- **核心目标**：买家查看当前会员等级、成长值进度、等级权益对比表，了解升级路径与下一等级权益，激励消费行为。
- **访问入口**：「我的」页会员卡入口；积分账户页会员入口；首页会员提醒。
- **实现状态**：✅ 已实现

## 2. 页面布局与信息架构
- **整体布局**：顶部 `van-nav-bar`（返回 + 标题「会员等级」）+ 当前等级卡 + 成长值进度 + 等级权益对比表 + 升级攻略，无 Tabbar。
- **关键区域**：
  - 区域 A（当前等级卡）：渐变背景（按等级配色），大字展示当前等级（如「V3 黄金会员」），下方成长值「3,860 / 5,000」与下一等级名称「V4 铂金」。
  - 区域 B（成长值进度条）：`van-progress` 展示当前成长值距下一等级进度百分比，下方「再消费 ¥X 即可升级」提示。
  - 区域 C（等级权益对比表）：`van-table` 或自定义网格展示 V0-V4 五个等级的权益对比（折扣率/生日礼/专属客服/积分倍数/免邮等），当前等级高亮。
  - 区域 D（升级攻略）：`van-cell-group` 展示获取成长值方式（消费 1 元 = 1 成长值、签到 +5、完成任务 +X）。
- **响应式断点**：375px 基准；≥768px 居中最大 480px。
- **首屏内容**：导航栏、当前等级卡、成长值进度。

## 3. 数据模型与 API 对接
- **服务归属**：Membership 域（旧域 PointsMembership 双轨兜底，端点路径不变）
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| GET | `/api/members/me` | 查询当前会员信息（含等级、成长值、权益） | Buyer |

- **请求参数**：无参数。
- **响应字段**：`MemberDto` 含 `userId`、`levelCode`（V0-V4）、`levelName`、`levelIcon`、`growthValue`、`nextLevelGrowthThreshold`、`nextLevelName`、`discountRate`、`benefits`（权益数组：生日礼/专属客服/积分倍数/免邮等）、`allLevels`（全部等级配置数组，用于权益对比表）。
- **数据加载策略**：进入页面调 `GET /api/members/me` 渲染等级卡、进度、权益对比表；下拉刷新。
- **缓存策略**：会员信息缓存 5 分钟（基于 userId）；下拉刷新强制更新。

## 4. 交互流程
- **主流程**：
  1. 进入页面 → `GET /api/members/me` → 渲染当前等级卡、成长值进度、权益对比表、升级攻略。
  2. 查看权益对比表 → 横向滚动查看 V0-V4 各等级权益。
  3. 查看升级攻略 → 了解获取成长值方式。
  4. 下拉刷新 → 重新拉取会员信息。
- **分支流程**：
  - 已达最高等级（V4）：进度条满格显示「已达最高等级」，无升级提示。
  - 等级降级（近 12 个月成长值不足）：状态卡显示「即将降级」警告 + 剩余天数。
- **跨页面流转**：无跳转（本页仅展示）；可点击「去消费升级」跳首页。
- **状态机可视化**：V0 → V1 → V2 → V3 → V4（按成长值升级，近 12 个月成长值不足降级）。

## 5. 组件清单
- **基础组件**：`van-nav-bar`、`van-cell`、`van-cell-group`、`van-progress`、`van-icon`、`van-tag`、`van-image`、`van-skeleton`、`van-toast`（showToast）、`van-pull-refresh`。
- **业务组件**：`MemberLevelCard` 当前等级卡（渐变背景 + 等级 + 成长值）；`GrowthValueProgress` 成长值进度条（含升级提示）；`LevelBenefitTable` 等级权益对比表（V0-V4 × 权益矩阵）；`UpgradeGuideCell` 升级攻略。
- **图表组件**：无（进度用 `van-progress`，对比表用网格）。
- **图标使用**：返回 `arrow-left`；权益已享 `success`；权益未享 `cross`；等级图标 `medal-o`/`diamond-o`/`crown-o`。
- **空状态**：不涉及（首屏必有数据）。

## 6. 视觉规范
- **主色应用**：等级卡渐变背景按等级配色（V0 `#8C8C8C`、V1 `#52C41A`、V2 `#1677FF`、V3 `#FAAD14`、V4 `#722ED1`）；成长值进度条主色；当前等级列高亮主色。
- **状态色**：已享权益 `#52C41A`；未享权益 `#8C8C8C`；即将降级警告 `#FF4D4F`；升级提示 `#1677FF`。
- **间距**：等级卡内边距 20px；进度条高 8px；权益对比表单元格 12px 内边距；攻略项间距 8px。
- **字体**：等级名称 24px semibold `#FFFFFF`；成长值 14px `rgba(255,255,255,0.9)`；进度百分比 14px semibold `#1677FF`；升级提示 13px `#1677FF`；表头 12px medium `#8C8C8C`；表体 13px `#000000D9`；攻略 13px `#595959`。
- **图标尺寸**：返回 20px；等级图标 32px；权益图标 16px。

## 7. 异常处理与边界
- **加载态**：首屏 `van-skeleton` 模拟等级卡 + 进度条 + 权益对比表。
- **空数据**：不涉及（首屏必有数据）。
- **错误态**：接口失败 `showToast` 「加载失败」+ 重试按钮；`van-pull-refresh` 下拉刷新。
- **权限控制**：Buyer 可见；未登录跳 `/login?redirect=/members/level`。
- **并发与乐观锁**：不涉及（只读页面）。
- **危险操作确认**：不涉及。

## 8. 验收要点
- [ ] 当前等级卡展示等级名称、成长值、下一等级。
- [ ] 成长值进度条展示当前进度百分比与升级提示。
- [ ] 权益对比表展示 V0-V4 五个等级权益对比，当前等级高亮。
- [ ] 升级攻略展示获取成长值方式。
- [ ] 已达最高等级（V4）进度条满格显示「已达最高等级」。
- [ ] 等级降级警告展示剩余天数。
- **性能要求**：首屏 < 1s；下拉刷新响应 < 1s。
- **可访问性**：进度 `role="progressbar" aria-valuenow="77"`；表格 `role="table"`；权益图标 `aria-label="已享"`/`aria-label="未享"`。
