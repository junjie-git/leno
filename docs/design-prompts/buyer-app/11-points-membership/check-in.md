# 每日签到 - 用户 APP

## 1. 页面定位
- **所属端**：用户 APP
- **所属模块**：11-points-membership 积分会员
- **页面类型**：功能页
- **目标用户**：买家（Buyer）
- **核心目标**：买家每日签到获取积分奖励，展示连续签到天数与本月签到日历，激励用户持续活跃。
- **访问入口**：积分账户页「每日签到」入口；首页签到提醒弹窗；「我的」页签到入口。
- **实现状态**：✅ 已实现

## 2. 页面布局与信息架构
- **整体布局**：顶部 `van-nav-bar`（返回 + 标题「每日签到」）+ 签到状态卡 + 连续签到奖励进度 + 本月日历 + 签到规则说明，无 Tabbar。
- **关键区域**：
  - 区域 A（签到状态卡）：渐变背景，展示连续签到天数「已连续签到 X 天」，下方「今日签到 +X 积分」按钮（已签到显示「已签到」+ 获得积分数）。
  - 区域 B（连续签到奖励进度）：横向 7 天进度条，每天图标 + 积分奖励数，第 7 天奖励翻倍；当前天数高亮，未达天数置灰。
  - 区域 C（本月日历）：`van-calendar` 自定义模式，展示本月每一天，已签到日期标主色圆点，今日高亮，未签到日期灰色；可点击今日签到。
  - 区域 D（签到规则说明）：`van-cell-group` 展示规则「每日签到 +5 积分；连续 7 天额外 +20 积分；中断后重新计算」。
- **响应式断点**：375px 基准；≥768px 居中最大 480px。
- **首屏内容**：导航栏、签到状态卡、连续签到奖励进度。

## 3. 数据模型与 API 对接
- **服务归属**：Points 域（旧域 PointsMembership 双轨兜底，端点路径不变）
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| POST | `/api/points/check-in` | 每日签到 | Buyer |
| GET | `/api/points/account` | 查询积分账户（含连续签到天数与上次签到日期） | Buyer |

- **请求参数**：签到无 body；账户查询无参数。
- **响应字段**：签到结果 `CheckInResultDto` 含 `awardedPoints`、`consecutiveDays`、`isBonusDay`、`newBalance`；账户 `PointsAccountDto` 含 `lastCheckInDate`、`consecutiveDays`、`balance`。
- **数据加载策略**：进入页面调 `GET /api/points/account` 获取连续签到天数与上次签到日期，渲染状态卡与日历；本月签到记录可前端按 `lastCheckInDate` 推算或扩展接口返回本月签到日期数组。
- **缓存策略**：账户信息缓存 30s；签到结果立即更新缓存。

## 4. 交互流程
- **主流程**：
  1. 进入页面 → `GET /api/points/account` → 渲染状态卡（连续天数 + 签到按钮）、奖励进度、本月日历。
  2. 点击「今日签到」→ 按钮 disabled + loading → `POST /api/points/check-in` → 成功 `showToast` 「签到成功，获得 X 积分」→ 更新状态卡（按钮置灰显示「已签到 +X」）、奖励进度、日历。
  3. 点击日历日期 → 仅查看，不可签到（仅今日可签到）。
  4. 查看签到规则说明。
- **分支流程**：
  - 今日已签到：签到按钮置灰显示「已签到 +X 积分」，点击无响应。
  - 签到失败：`showToast` 「签到失败」+ 重试。
  - 连续签到中断：奖励进度重置为 D1，提示「中断后重新计算」。
- **跨页面流转**：无跳转（本页内完成签到）。
- **状态机可视化**：未签到 → 签到中(loading) → 已签到(置灰) / 签到失败(提示)。

## 5. 组件清单
- **基础组件**：`van-nav-bar`、`van-button`、`van-cell`、`van-cell-group`、`van-calendar`（自定义模式）、`van-image`、`van-skeleton`、`van-toast`（showToast）、`van-icon`。
- **业务组件**：`CheckInStatusCard` 签到状态卡（渐变背景 + 连续天数 + 签到按钮）；`ConsecutiveDaysProgress` 连续签到奖励进度（7 天横向）；`MonthlyCheckInCalendar` 本月签到日历（自定义日期单元格）；`CheckInRulesCell` 规则说明。
- **图表组件**：无。
- **图标使用**：返回 `arrow-left`；签到 `calendar-o`；已签到 `success`；奖励 `gift-o`。
- **空状态**：不涉及（首屏必有数据）。

## 6. 视觉规范
- **主色应用**：状态卡渐变背景 `linear-gradient(135deg, #1677FF, #0958D9)`；签到按钮 `#FFFFFF` 主色文字；日历今日高亮主色；已签到日期主色圆点。
- **状态色**：已签到 `#52C41A`；未签到 `#8C8C8C`；今日高亮 `#1677FF`；奖励翻倍 `#FF4D4F`。
- **间距**：状态卡内边距 20px；奖励进度项间距 8px；日历单元格 40×40px；规则说明内边距 12px。
- **字体**：连续天数 30px semibold `#FFFFFF`；签到按钮 16px semibold 主色；奖励积分 12px；日历日期 14px `#000000D9`；规则说明 13px `#595959`。
- **图标尺寸**：返回 20px；签到 24px；已签到 16px。

## 7. 异常处理与边界
- **加载态**：首屏 `van-skeleton` 模拟状态卡 + 奖励进度 + 日历。
- **空数据**：不涉及（首屏必有数据）。
- **错误态**：接口失败 `showToast` 「加载失败」+ 重试按钮。
- **权限控制**：Buyer 可见；未登录跳 `/login?redirect=/points/check-in`。
- **并发与乐观锁**：签到按钮点击后立即 disabled + loading 直至响应返回；`Idempotency-Key` 头防重复签到。
- **危险操作确认**：不涉及。
