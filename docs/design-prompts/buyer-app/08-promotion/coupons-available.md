# 可领取优惠券 - 用户 APP

## 1. 页面定位
- **所属端**：用户 APP
- **所属模块**：08-promotion 优惠
- **页面类型**：列表页
- **目标用户**：买家（Buyer）
- **核心目标**：买家查看当前可领取的优惠券列表，点击「立即领取」领取优惠券，领取成功后可在「我的优惠券」中查看。
- **访问入口**：「我的」页优惠券入口；首页活动 banner；结算页「去领取」CTA。
- **实现状态**：✅ 已实现

## 2. 页面布局与信息架构
- **整体布局**：顶部 `van-nav-bar`（返回+标题「领券中心」）+ `van-list` 无限滚动优惠券卡片列表，无 Tabbar。
- **关键区域**：
  - 区域 A（优惠券卡片）：每张卡片左侧金额区（面额+币种）+ 右侧信息区（名称+门槛+有效期+「立即领取」按钮），使用 `van-card` 自定义样式，左侧背景主色渐变。
  - 区域 B（已领取标签）：已领取的券显示「已领取」灰色标签，按钮置灰。
  - 区域 C（空状态）：`van-empty`「暂无可领优惠券」+ 「去逛逛」CTA。
- **响应式断点**：375px 基准；≥768px 居中最大 480px。
- **首屏内容**：导航栏、可领取优惠券卡片首屏。

## 3. 数据模型与 API 对接
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| GET | `/api/coupons/available` | 查询可领取优惠券列表 | Buyer |
| POST | `/api/coupons/{couponId}/receive` | 领取优惠券 | Buyer |

- **请求参数**：`GET /api/coupons/available` 无参数；领取 `couponId` 路径参数，`source` query 参数默认 `Manual`。
- **响应字段**：`CouponDto` 含 `id`、`name`、`denomination`、`threshold`、`currency`、`validFrom`、`validTo`、`status`、`received`（当前用户是否已领取）；`UserCouponDto` 含 `id`、`couponId`、`status`、`receivedAt`。
- **数据加载策略**：进入页面调用 `GET /api/coupons/available` 全量加载；领取后局部更新对应券的 `received` 状态。
- **缓存策略**：可领券列表缓存 5 分钟；领取后立即失效缓存。

## 4. 交互流程
- **主流程**：
  1. 进入页面 → `GET /api/coupons/available` → 渲染优惠券卡片列表。
  2. 点击「立即领取」→ 按钮 disabled + loading → `POST /api/coupons/{couponId}/receive` → 成功 `showToast` 「领取成功」+ 卡片标记「已领取」。
  3. 已领取的券按钮置灰，不可重复领取。
  4. 滚动到底部 → `van-list` load 追加（若支持分页）。
  5. 下拉刷新 → 重新加载列表。
- **分支流程**：
  - 领取失败：显示后端错误（如「已领完」「已达领取上限」）3s。
  - 空列表：`van-empty`「暂无可领优惠券」+ 「去逛逛」CTA 跳首页。
  - 已领完：卡片标记「已抢光」，按钮置灰。
- **跨页面流转**：跳「我的优惠券」页（`/coupons/mine`）；跳首页继续购物。
- **状态机可视化**：可领取 → 领取中(loading) → 已领取(置灰) / 已抢光(置灰)。

## 6. 视觉规范
- **主色应用**：优惠券左侧金额区主色 `#1677FF` 渐变背景；「立即领取」按钮主色；金额文字白色。
- **状态色**：金额 `#FFFFFF`（主色背景）；门槛 `#595959`；有效期 `#8C8C8C`；已领取标签 `#8C8C8C`；已抢光标签 `#FF4D4F`。
- **间距**：卡片间距 12px；卡片内边距 12px；金额区宽 80px。
- **字体**：金额 24px semibold `#FFFFFF`；券名 16px medium `#000000D9`；门槛 12px `#595959`；有效期 12px `#8C8C8C`；按钮 14px。
- **图标尺寸**：返回 20px；优惠券 20px。

## 7. 异常处理与边界
- **加载态**：首屏 `van-skeleton` 模拟 3 张优惠券卡片。
- **空数据**：`van-empty`「暂无可领优惠券」+ 「去逛逛」CTA。
- **错误态**：接口失败 `showToast` 「加载失败」+ 重试按钮；`van-pull-refresh` 下拉刷新。
- **权限控制**：Buyer 可见；未登录跳 `/login?redirect=/coupons/available`。
- **并发与乐观锁**：领取按钮点击后立即 disabled + loading；`Idempotency-Key` 头防重复领取。
- **危险操作确认**：不涉及（领取非危险操作）。

- [ ] 点击「立即领取」成功后标记「已领取」。
- [ ] 已领取的券按钮置灰不可重复领取。
- [ ] 领取失败显示后端错误信息。
- [ ] 空列表展示「去逛逛」CTA。
- **性能要求**：首屏 < 1s；图片懒加载；领取响应 < 1s。
