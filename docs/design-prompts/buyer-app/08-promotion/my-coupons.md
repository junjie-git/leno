# 我的优惠券 - 用户 APP

## 1. 页面定位
- **所属端**：用户 APP
- **所属模块**：08-promotion 优惠
- **页面类型**：列表页
- **目标用户**：买家（Buyer）
- **核心目标**：买家查看已领取的优惠券，按状态（可用/已用/已过期）筛选，并在结算时选用可用券。
- **访问入口**：「我的」页优惠券入口；领券中心跳转；结算页「优惠券」点击跳转。
- **实现状态**：✅ 已实现

## 2. 页面布局与信息架构
- **整体布局**：顶部 `van-nav-bar`（返回+标题「我的优惠券」+「领券中心」入口）+ `van-tabs` 状态筛选（可用/已用/已过期）+ `van-list` 优惠券卡片列表，无 Tabbar。
- **关键区域**：
  - 区域 A（状态筛选 Tab）：`van-tabs` 3 个标签，切换后重新加载对应状态券，可用 Tab 显示数量角标。
  - 区域 B（优惠券卡片）：可用券卡片左侧金额区主色背景+右侧信息区（名称+门槛+有效期+「去使用」按钮）；已用/已过期券卡片置灰。
  - 区域 C（空状态）：`van-empty`「暂无优惠券」+ 「去领取」CTA 跳领券中心。
- **响应式断点**：375px 基准；≥768px 居中最大 480px。
- **首屏内容**：导航栏、状态筛选 Tab、优惠券卡片首屏。

## 3. 数据模型与 API 对接
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| GET | `/api/coupons/mine` | 查询我的优惠券（按状态过滤） | Buyer |

- **请求参数**：`GET /api/coupons/mine?status={CouponStatus}`；status 可空表示全部，枚举 `Usable/Used/Expired`。
- **响应字段**：`UserCouponDto` 含 `id`、`couponId`、`name`、`denomination`、`threshold`、`currency`、`validFrom`、`validTo`、`status`、`receivedAt`、`usedAt`、`orderId`。
- **数据加载策略**：进入页面默认「可用」Tab → `GET /api/coupons/mine?status=Usable`；切换 Tab 重新加载；下拉刷新。
- **缓存策略**：不缓存，每次切换 Tab 重新拉取；结算页选用券后返回时刷新。

## 4. 交互流程
- **主流程**：
  1. 进入页面 → 默认「可用」Tab → `GET /api/coupons/mine?status=Usable` → 渲染可用券卡片。
  2. 切换状态 Tab → 重置列表 → `GET /api/coupons/mine?status={status}`。
  3. 可用券点击「去使用」→ 跳首页或对应商品页（根据券适用范围）。
  4. 点击「领券中心」→ 跳 `/coupons/available`。
  5. 下拉刷新 → 重新加载当前 Tab。
- **分支流程**：
  - 空列表：`van-empty`「暂无{状态}优惠券」+ 「去领取」CTA（仅可用 Tab）。
  - 已用券：展示使用时间与订单号，卡片置灰。
  - 已过期券：展示过期时间，卡片置灰。
- **跨页面流转**：领券中心、首页、商品页（去使用）。
- **状态机可视化**：可用(可使用) → 已用(置灰) / 已过期(置灰)。

## 6. 视觉规范
- **主色应用**：可用券左侧金额区主色 `#1677FF` 渐变背景；「去使用」按钮主色；领券中心链接主色。
- **状态色**：可用金额 `#FFFFFF`（主色背景）；已用/已过期金额 `#8C8C8C`（灰色背景）；门槛 `#595959`；有效期 `#8C8C8C`；已用标签 `#8C8C8C`；已过期标签 `#8C8C8C`。
- **间距**：卡片间距 12px；卡片内边距 12px；金额区宽 80px。
- **字体**：金额 24px semibold；券名 16px medium `#000000D9`；门槛 12px `#595959`；有效期 12px `#8C8C8C`；按钮 14px。
- **图标尺寸**：返回 20px；领券 20px；箭头 16px。

## 7. 异常处理与边界
- **加载态**：首屏 `van-skeleton` 模拟 3 张优惠券卡片。
- **空数据**：`van-empty`「暂无{状态}优惠券」+ 「去领取」CTA（仅可用 Tab 显示）。
- **错误态**：接口失败 `showToast` 「加载失败」+ 重试按钮；`van-pull-refresh` 下拉刷新。
- **权限控制**：Buyer 可见；未登录跳 `/login?redirect=/coupons/mine`。
- **并发与乐观锁**：不涉及（只读页面）。
- **危险操作确认**：不涉及。
