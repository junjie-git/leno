# 通知偏好 - 用户 APP

## 1. 页面定位
- **所属端**：用户 APP
- **所属模块**：12-notification 通知
- **页面类型**：表单页
- **目标用户**：买家（Buyer）
- **核心目标**：买家按事件类型与渠道（站内信/短信/邮件）配置通知偏好，控制接收哪些通知、通过哪些渠道接收。
- **访问入口**：「我的」页设置 → 通知偏好；消息列表页设置图标。
- **实现状态**：✅ 已实现

## 2. 页面布局与信息架构
- **整体布局**：顶部 `van-nav-bar`（返回 + 标题「通知偏好」）+ 可滚动主体（按事件分组的开关矩阵）+ 底部固定保存按钮，无 Tabbar。
- **关键区域**：
  - 区域 A（事件分组）：按事件类型分组（订单通知/促销通知/积分通知/系统通知），每个分组下多个事件项。
  - 区域 B（渠道开关矩阵）：每个事件项展示事件名称 + 3 个渠道开关（站内信/短信/邮件）；站内信默认开启且不可关闭，短信/邮件可切换。
  - 区域 C（免打扰时段）：`van-cell` + `van-switch` 开启免打扰，开启后显示时间区间选择（如 22:00-08:00）。
  - 区域 D（底部保存栏）：「保存设置」主色按钮。
- **响应式断点**：375px 基准；≥768px 居中最大 480px。
- **首屏内容**：导航栏、订单通知分组、积分通知分组。

## 3. 数据模型与 API 对接
- **服务归属**：UserCenter 域（HTTP 端点 `/api/users/me/notification-preferences`）+ Notification 域（内部协作）；旧域 UserAuth 双轨兜底，端点路径不变
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| GET | `/api/users/me/notification-preferences` | 查询我的通知偏好 | Buyer |
| PUT | `/api/users/me/notification-preferences` | 设置某事件渠道偏好 | Buyer |

- **请求参数**：查询无参数；设置 body `{ eventType, channel, enabled }`，每次设置一个事件的一个渠道；免打扰时段可扩展为 `{ dndEnabled, dndStart, dndEnd }`。
- **响应字段**：偏好 `NotificationPreferenceDto` 含 `preferences`（数组：`{ eventType, channels: { inApp, sms, email } }`）、`dndEnabled`、`dndStart`、`dndEnd`。
- **数据加载策略**：进入页面调 `GET /api/users/me/notification-preferences` 渲染开关矩阵；保存时按渠道逐个调用 PUT（或扩展为批量 PUT）。
- **缓存策略**：偏好缓存 5 分钟；保存后立即更新缓存。

## 4. 交互流程
- **主流程**：
  1. 进入页面 → `GET /api/users/me/notification-preferences` → 渲染事件分组与开关矩阵。
  2. 切换渠道开关 → `van-switch` change → 实时调用 `PUT /api/users/me/notification-preferences`（乐观更新）→ 成功 `showToast` 「已更新」/ 失败回滚。
  3. 切换免打扰开关 → 开启后显示时间区间选择 → 点击时间区间 → `van-picker` 弹出时间选择 → 确认后保存。
  4. 点击「保存设置」→ 批量提交未实时保存的变更 → 成功 `showToast` 「保存成功」→ 返回。
- **分支流程**：
  - 站内信开关：默认开启且不可关闭（保证关键通知触达）。
  - 实时保存失败：回滚开关状态 + `showToast` 「保存失败」+ 重试。
  - 免打扰时段内：站内信仍展示，短信/邮件延迟到时段外发送。
- **跨页面流转**：保存成功返回上一页。
- **状态机可视化**：开关关闭 → 开启中(loading) → 已开启 / 开启失败(回滚)。

## 5. 组件清单
- **基础组件**：`van-nav-bar`、`van-cell`、`van-cell-group`、`van-switch`、`van-button`、`van-picker`（时间选择）、`van-popup`、`van-skeleton`、`van-toast`（showToast）、`van-icon`。
- **业务组件**：`NotificationPreferenceGroup` 事件分组容器；`ChannelSwitchMatrix` 渠道开关矩阵（站内信/短信/邮件）；`DndSettingsCell` 免打扰设置项（含开关与时间区间）。
- **图表组件**：无。
- **图标使用**：返回 `arrow-left`；订单 `shopping-cart-o`；促销 `gift-o`；积分 `gold-coin-o`；系统 `bell`；箭头 `arrow`。
- **空状态**：不涉及（首屏必有数据）。

## 6. 视觉规范
- **主色应用**：开关激活态主色 `#1677FF`；保存按钮主色；分组标题主色。
- **状态色**：开关开启 `#1677FF`；开关关闭 `#8C8C8C`；站内信禁用 `#E5E5E5`。
- **间距**：分组间距 12px；分组内边距 12px；事件项内边距 12px；渠道开关间距 16px；底部保存栏高 50px。
- **字体**：分组标题 14px medium `#000000D9`；事件名称 14px `#000000D9`；渠道标签 12px `#8C8C8C`；保存按钮 16px semibold `#FFFFFF`。
- **图标尺寸**：返回 20px；事件图标 20px；箭头 16px。

## 7. 异常处理与边界
- **加载态**：首屏 `van-skeleton` 模拟分组与开关矩阵。
- **空数据**：不涉及（首屏必有数据，默认偏好）。
- **错误态**：查询失败 `showToast` 「加载失败」+ 重试按钮；保存失败回滚开关 + `showToast` 「保存失败」。
- **权限控制**：Buyer 可见；未登录跳 `/login?redirect=/notifications/preferences`。
- **并发与乐观锁**：开关切换乐观更新，失败回滚；保存按钮点击后立即 disabled + loading 直至响应返回；`Idempotency-Key` 头防重复保存。
- **危险操作确认**：不涉及。

## 8. 验收要点
- [ ] 事件按分组展示（订单/促销/积分/系统）。
- [ ] 每个事件展示 3 个渠道开关（站内信/短信/邮件）。
- [ ] 站内信开关默认开启且不可关闭。
- [ ] 渠道开关切换实时保存，失败回滚。
- [ ] 免打扰开关开启后显示时间区间选择。
- [ ] 「保存设置」按钮批量提交变更。
- [ ] 保存防重复（按钮 loading + Idempotency-Key）。
- **性能要求**：首屏 < 1s；开关切换响应 < 800ms；保存响应 < 1.5s。
- **可访问性**：开关 `role="switch" aria-checked="true"`；分组 `role="group"`；按钮 `aria-label`。
