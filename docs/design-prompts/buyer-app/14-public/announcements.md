# 公告 - 用户 APP

## 1. 页面定位
- **所属端**：用户 APP
- **所属模块**：14-public 公共
- **页面类型**：列表页
- **目标用户**：买家（Buyer）/ 游客
- **核心目标**：买家/游客查看平台发布的有效公告（活动/维护/政策等），点击查看公告详情。
- **访问入口**：首页公告滚动条「查看全部」；「我的」页公告入口；消息中心系统通知。
- **实现状态**：✅ 已实现

## 2. 页面布局与信息架构
- **整体布局**：顶部 `van-nav-bar`（返回 + 标题「平台公告」）+ `van-list` 公告卡片无限滚动，无 Tabbar。
- **关键区域**：
  - 区域 A（公告卡片）：每张卡片展示类型标签（活动/维护/政策/公告）+ 标题 + 摘要 + 发布时间；点击跳转详情。
  - 区域 B（置顶公告）：置顶公告排在列表顶部，带「置顶」标签。
  - 区域 C（空状态）：`van-empty`「暂无公告」+ 「去逛逛」CTA。
- **响应式断点**：375px 基准；≥768px 居中最大 480px。
- **首屏内容**：导航栏、公告卡片首屏。
- **线框图描述**：

## 3. 数据模型与 API 对接
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| GET | `/api/announcements` | 分页查询当前有效公告 | 公开（Buyer/Seller/Operator/Admin） |

- **请求参数**：`GET /api/announcements?page={page}&pageSize=20`；服务端仅返回已发布且未过期的公告。
- **响应字段**：`AnnouncementListResultDto` 含 `items`、`total`、`page`、`pageSize`；item 含 `announcementId`、`title`、`summary`、`content`、`type`（Activity/Maintenance/Policy/Notice）、`isPinned`、`publishedAt`、`expireAt`。
- **数据加载策略**：`van-list` 无限滚动，每页 20 条；下拉刷新。
- **缓存策略**：列表缓存 5 分钟；下拉刷新强制更新。

## 4. 交互流程
- **主流程**：
  1. 进入页面 → `GET /api/announcements?page=1` → 渲染公告卡片（置顶公告排顶部）。
  2. 滚动到底部 → `van-list` load → 追加下一页。
  3. 点击公告卡片 → `van-popup` 弹出公告详情（标题 + 正文 + 发布时间 + 类型标签）。
  4. 下拉刷新 → 重置列表重新拉取。
- **分支流程**：
  - 空列表：`van-empty`「暂无公告」+ 「去逛逛」CTA 跳首页。
  - 接口失败：`showToast` 「加载失败」+ 重试按钮。
  - 公告已过期：列表不展示（服务端过滤）。
- **跨页面流转**：无跳转（详情在弹层展示）；「去逛逛」跳首页。
- **状态机可视化**：无（只读列表）。

## 5. 组件清单
- **基础组件**：`van-nav-bar`、`van-list`、`van-pull-refresh`、`van-cell`、`van-tag`、`van-popup`、`van-icon`、`van-empty`、`van-skeleton`、`van-toast`（showToast）。
- **业务组件**：`AnnouncementCard` 公告卡片（含类型标签、标题、摘要、时间、置顶标签）；`AnnouncementDetailPopup` 公告详情弹层；`AnnouncementTypeTag` 类型标签；`EmptyState`（见 shared/components.md §5）。
- **图表组件**：无。
- **图标使用**：返回 `arrow-left`；活动 `gift-o`；维护 `setting-o`；政策 `description`；公告 `bell`；置顶 `top-o`。
- **空状态**：`van-empty`「暂无公告」+ 「去逛逛」CTA 跳首页。

## 6. 视觉规范
- **主色应用**：置顶标签主色 `#1677FF`；标题主色（点击态）。
- **状态色**：活动 `#FF4D4F`；维护 `#FAAD14`；政策 `#1677FF`；公告 `#52C41A`；置顶 `#FF4D4F`。
- **间距**：卡片间距 12px；卡片内边距 12px。
- **字体**：公告标题 15px medium `#000000D9`（2 行省略）；公告摘要 13px `#595959`（2 行省略）；发布时间 12px `#8C8C8C`；类型标签 11px。
- **图标尺寸**：返回 20px；类型图标 20px；置顶图标 12px。

## 7. 异常处理与边界
- **加载态**：首屏 `van-skeleton` 模拟 5 张公告卡片。
- **空数据**：`van-empty`「暂无公告」+ 「去逛逛」CTA 跳首页。
- **错误态**：接口失败 `showToast` 「加载失败」+ 重试按钮；`van-pull-refresh` 下拉刷新。
- **权限控制**：公开页面，游客可访问。
- **并发与乐观锁**：不涉及（只读列表）。
- **危险操作确认**：不涉及。

- [ ] 公告卡片展示类型标签、标题、摘要、发布时间。
- [ ] 置顶公告排顶部，带「置顶」标签。

- [ ] 列表无限滚动加载下一页。

- **性能要求**：首屏 < 1s；列表无限滚动无卡顿；分页 pageSize=20。
