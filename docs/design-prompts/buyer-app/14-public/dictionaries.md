# 数据字典 - 用户 APP

## 1. 页面定位
- **所属端**：用户 APP
- **所属模块**：14-public 公共
- **页面类型**：嵌入页（工具页）
- **目标用户**：买家（Buyer）/ 游客
- **核心目标**：买家/游客按字典编码查询字典项（如省市区/性别/退款原因等），用于表单选项填充；本页面为开发者工具页，普通用户不直接访问，仅作前端组件引用说明。
- **访问入口**：不直接访问；前端组件（如 `van-picker` 选项）通过 API 引用字典项。
- **实现状态**：✅ 已实现

## 2. 页面布局与信息架构
- **整体布局**：顶部 `van-nav-bar`（返回 + 标题「数据字典」）+ 字典编码搜索框 + 字典项列表，无 Tabbar。
- **关键区域**：
  - 区域 A（字典编码搜索）：`van-search` 输入字典编码（如 `gender`、`refund-reason`），点击搜索查询。
  - 区域 B（字典项列表）：`van-cell` 列表展示字典项 label + value + 排序；支持复制 value。
  - 区域 C（空状态）：`van-empty`「请输入字典编码查询」。
- **响应式断点**：375px 基准；≥768px 居中最大 480px。
- **首屏内容**：导航栏、字典编码搜索框、空状态提示。

## 3. 数据模型与 API 对接
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| GET | `/api/dictionaries/{code}` | 按编码获取字典（含字典项） | 公开（Buyer/Seller/Operator/Admin） |

- **请求参数**：`code` 路径参数，字典编码（如 `gender`、`refund-reason`、`order-status`）。
- **响应字段**：`DataDictionaryDto` 含 `dictionaryId`、`code`、`name`、`status`、`items`（数组：`{ itemId, label, value, sortOrder, isDefault }`）。
- **数据加载策略**：输入编码点击搜索 → `GET /api/dictionaries/{code}` → 渲染字典项列表。
- **缓存策略**：字典项缓存 10 分钟（基于 code，前端 localStorage）；高频字典（如省市区）可预加载。

## 4. 交互流程
- **主流程**：
  1. 进入页面 → 展示空状态「请输入字典编码查询」。
  2. 输入字典编码 → 点击搜索 → `GET /api/dictionaries/{code}` → 渲染字典项列表。
  3. 点击字典项 value → `clipboard` 写入剪贴板 → `showToast` 「已复制」。
  4. 重新输入编码 → 重新搜索。
- **分支流程**：
  - 字典不存在：`showToast` 「字典不存在」+ 清空列表。
  - 字典已停用：`showToast` 「字典已停用」+ 清空列表。
  - 空字典项：`van-empty`「字典无项目」。
- **跨页面流转**：无跳转（工具页）。
- **状态机可视化**：无（只读查询）。

## 5. 组件清单
- **基础组件**：`van-nav-bar`、`van-search`、`van-cell`、`van-cell-group`、`van-tag`、`van-icon`、`van-empty`、`van-skeleton`、`van-toast`（showToast）。
- **业务组件**：`DictionarySearchBar` 字典编码搜索框；`DictionaryItemList` 字典项列表；`DictionaryItemCell` 字典项单元格（含 label、value、复制按钮）；`EmptyState`（见 shared/components.md §5）。
- **图表组件**：无。
- **图标使用**：返回 `arrow-left`；搜索 `search`；复制 `description`；默认值 `star-o`。
- **空状态**：`van-empty`「请输入字典编码查询」/「字典无项目」。

## 6. 视觉规范
- **主色应用**：搜索按钮主色 `#1677FF`；字典编码主色；默认值标签主色。
- **状态色**：默认值标签 `#1677FF`；停用 `#8C8C8C`。
- **间距**：搜索框内边距 12px；字典项间距 8px；字典项内边距 12px。
- **字体**：字典名称 16px medium `#000000D9`；字典编码 12px `#8C8C8C`；字典项 label 14px `#000000D9`；字典项 value 14px `#1677FF`（等宽字体）；提示文字 12px `#8C8C8C`。
- **图标尺寸**：返回 20px；搜索 16px；复制 16px。

## 7. 异常处理与边界
- **加载态**：搜索时 `van-skeleton` 模拟字典项列表。
- **空数据**：未搜索 `van-empty`「请输入字典编码查询」；字典无项目 `van-empty`「字典无项目」。
- **错误态**：字典不存在 `showToast` 「字典不存在」+ 清空列表；接口失败 `showToast` 「查询失败」+ 重试。
- **权限控制**：公开页面，游客可访问；普通用户不直接访问（开发者工具页）。
- **并发与乐观锁**：不涉及（只读查询）。
- **危险操作确认**：不涉及。

## 8. 验收要点
- [ ] 字典编码搜索框输入编码后点击搜索查询。
- [ ] 字典项列表展示 label、value、排序。
- [ ] 默认值字典项标记「默认」标签。
- [ ] 点击字典项 value 复制到剪贴板。
- [ ] 字典不存在/已停用提示对应文案。
- [ ] 未搜索时展示「请输入字典编码查询」空状态。
- **性能要求**：查询响应 < 800ms；字典项缓存 10 分钟。
- **可访问性**：搜索框 `role="searchbox"`；列表 `role="list"`；按钮 `aria-label="复制"`。
