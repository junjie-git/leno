# 资质管理 - 商家管理后台

## 1. 页面定位
- **所属端**：商家管理后台
- **所属模块**：01-onboarding（入驻与店铺）
- **页面类型**：列表页 + 表单页（混合）
- **目标用户**：卖家（Seller）
- **核心目标**：卖家维护店铺资质材料（营业执照、特许经营证等），上传新证照、查看现有资质与有效期，临期资质及时续期。
- **访问入口**：Sider「店铺设置 → 资质管理」；店铺资料页快捷入口；资质临期通知引导。
- **实现状态**：✅ 已实现

## 2. 页面布局与信息架构
- **整体布局**：顶部面包屑 + 顶部提示条（临期/过期资质警告）+ 资质列表表格 + 右侧抽屉上传新资质。
- **关键区域**：
  - 区域 A（面包屑）：首页 / 店铺设置 / 资质管理。
  - 区域 B（临期提示条）：存在临期（≤7 天）或过期资质时，顶部 `<a-alert type="warning">` 横幅展示「N 份资质即将过期，请及时续期上传新证照」。
  - 区域 C（资质列表 `<a-table>`）：列含资质类型、证照编号、证照图片缩略图、生效日期、失效日期、状态（有效/临期/过期）、操作（查看大图、替换）。>100 行启用虚拟滚动。
  - 区域 D（右上角操作）：「上传新资质」按钮，点击右侧 `<a-drawer>` 滑出上传表单。
  - 区域 E（抽屉表单）：资质类型（`<a-select>` 营业执照/身份证/特许经营证/其他）、证照编号、证照图片上传、生效日期、失效日期（空表示长期有效）。
- **响应式断点**：≥1200px 表格全宽；992-1199px 表格横向滚动 `<a-table :scroll="{ x: 1000 }" />`；<992px 不支持。
- **首屏内容**：临期提示条（若有）+ 资质列表前 10 行。

## 3. 数据模型与 API 对接
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| POST | `/api/shops/me/qualifications` | 上传店铺资质（含证照图片文件） | Seller |
| GET | `/api/shops/me` | 查询店铺资料（含资质集合） | Seller |

- **请求参数**：`SubmitQualificationDto`（multipart/form-data）含 `type`(BusinessLicense/IdCard/SpecialPermit/Other)、`certificateNo`、`validFrom`、`validUntil?`(空表示长期有效)、`file`(证照图片文件，IFormFile)。
- **响应字段**：`QualificationDto` 含 `type`、`certificateNo`、`imageUrl`、`validFrom`、`validUntil?`。前端根据 `validUntil` 与当前日期差值计算状态：>30 天「有效」、≤7 天「临期」(warning)、<当前「过期」(error)。
- **数据加载策略**：进入页面调用 `GET /api/shops/me`，从 `qualifications` 字段提取资质列表。
- **缓存策略**：不缓存，每次进入实时加载。

## 4. 交互流程
- **主流程**：
  1. 卖家进入页面 → 调用 `GET /api/shops/me` → 渲染资质列表与临期提示。
  2. 卖家点击「上传新资质」→ 右侧抽屉滑出 → 填写资质信息并上传图片。
  3. 卖家点击「提交」→ 前端校验通过 → 调用 `POST /api/shops/me/qualifications`（multipart）→ 成功 `message.success('资质上传成功')` → 关闭抽屉，刷新列表。
  4. 卖家点击「查看」→ `<a-image>` 预览大图。
  5. 卖家点击「替换」→ 抽屉预填原资质信息 → 修改后提交（实质为新增 + 旧资质保留，由后端处理）。
- **分支流程**：
  - 资质集合移除全部营业执照：后端返回 400，`message.error('至少保留一份有效营业执照')`。
  - 证照有效期非法（生效≥失效）：前端校验拦截，字段标红。
  - 图片格式不支持：前端上传前校验扩展名，`message.error('仅支持 JPG/PNG/WebP')`。
- **跨页面流转**：临期提示条点击「上传新资质」打开抽屉；上传成功后留在本页刷新列表。
- **状态机可视化**：资质状态由 `validUntil` 派生：有效（>30 天或长期）→ 临期（≤7 天）→ 过期（<当前日期）。资质过期不自动暂停店铺，但触发续期提醒。

- **基础组件**：`<a-table>`、`<a-alert>`、`<a-drawer>`、`<a-form>`、`<a-select>`、`<a-date-picker>`、`<a-upload>`、`<a-image>`、`<a-checkbox>`、`<a-tag>`。

- **主色应用**：「上传新资质」按钮、提交按钮、查看链接使用主色 `#1677FF`。
- **状态色**：有效绿 `#52C41A`、临期黄 `#FAAD14`、过期红 `#FF4D4F`；临期提示条 warning 黄 `#FAAD14` 背景浅色。

## 7. 异常处理与边界
- **加载态**：进入页面 `<a-skeleton>` 模拟表格布局；上传时按钮 loading。
- **空数据**：无资质时 `<EmptyState>` 引导上传，特别提示「至少上传一份营业执照」。
- **错误态**：网络错误 `message.error('网络异常')`；403 `message.error('无权限访问')`；400（资质完整性）展示后端返回的原因。
- **权限控制**：仅店铺所属卖家可上传资质；资质变更后由后端触发运营复核提醒。
- **并发与乐观锁**：资质上传为新增操作，无乐观锁；并发上传相同证照编号由后端唯一性校验拦截。
- **危险操作确认**：上传资质非危险操作，无二次确认；「替换」操作实质为新增，旧资质保留，无需确认。

## 8. 验收要点
- [ ] 资质列表正确展示类型、编号、图片缩略图、生效/失效日期与状态
- [ ] 临期（≤7 天）与过期资质顶部提示条正确显示数量
- [ ] 上传抽屉表单校验：资质类型必选、编号必填、图片必传（JPG/PNG/WebP ≤5MB）、生效日期必填、失效日期须晚于生效（或勾选长期有效）
- [ ] 「查看」点击后 `<a-image>` 大图预览
- [ ] 至少保留一份有效营业执照的约束在前端提示（移除时拦截）
- **性能要求**：首屏加载 < 1s；图片上传 5MB ≤ 3s；表格 >100 行启用虚拟滚动。
- **可访问性**：表格有 `aria-label`；图片缩略图有 `alt` 描述；抽屉支持键盘关闭（Esc）；对比度满足 WCAG AA。
