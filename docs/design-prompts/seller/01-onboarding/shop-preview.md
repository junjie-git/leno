# 店铺前台预览 - 商家管理后台

## 1. 页面定位
- **所属端**：商家管理后台
- **所属模块**：01-onboarding（入驻与店铺）
- **页面类型**：嵌入页（预览页）
- **目标用户**：卖家（Seller）
- **核心目标**：卖家预览买家视角的店铺前台展示，确认店铺名称、Logo、描述、客服信息与商品列表的展示效果。
- **访问入口**：店铺资料页「预览店铺前台」按钮；Sider「店铺设置 → 店铺前台预览」。
- **实现状态**：🚧 规划中

## 2. 页面布局与信息架构
- **整体布局**：顶部面包屑 + 顶部提示条「预览模式，买家看到的内容如下」+ 居中店铺前台卡片（最大宽度 1200px），模拟买家 APP/网页店铺页布局。
- **关键区域**：
  - 区域 A（面包屑）：首页 / 店铺设置 / 店铺前台预览。
  - 区域 B（顶部提示条）：`<a-alert type="info" message="预览模式：以下为买家看到的店铺前台展示" banner />`。
  - 区域 C（店铺头部）：店铺 Logo（128px）+ 店铺名称（`24px` semibold）+ 描述文字 + 关注/收藏按钮（仅展示，不可点击）。
  - 区域 D（店铺信息栏）：客服电话（脱敏）、客服邮箱、店铺评分（`<a-rate>` 只读）、商品数、销量。
  - 区域 E（商品瀑布流）：`<a-list>` 网格布局展示在售商品卡片（主图、标题、价格、销量），点击不可跳转（预览模式）。
- **响应式断点**：≥1200px 居中 1200px；992-1199px 满栏自适应；<992px 不支持。
- **首屏内容**：店铺头部 + 店铺信息栏 + 商品瀑布流前 8 个。

## 3. 数据模型与 API 对接
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| GET | `/api/shops/me` | 查询店铺资料（含名称、Logo、描述、客服） | Seller |
| GET | `/api/products?shopId={myShopId}&status=Listed` | 查询本店在售商品 | Seller |

- **请求参数**：商品列表查询 `ProductQueryDto` 含 `shopId`(当前卖家店铺 ID)、`status=Listed`、`page`、`pageSize`。
- **响应字段**：`ShopDto` 提供店铺信息；`PageResult<ProductDto>` 提供商品列表，含 `name`、`mainImages`、`priceRange`、`soldCount`。店铺评分 `score` 由评价域事件回写。
- **数据加载策略**：进入页面并行调用 `GET /api/shops/me` 与 `GET /api/products?status=Listed`；商品分页加载，每页 20 条。
- **缓存策略**：店铺信息缓存 5 分钟（键 `seller:shop-preview:{sellerId}`），商品列表不缓存。

## 4. 交互流程
- **主流程**：
  1. 卖家进入页面 → 并行调用店铺资料与商品列表 API → 渲染预览。
  2. 卖家浏览店铺头部与信息栏，确认展示效果。
  3. 卖家滚动商品瀑布流 → 触底分页加载下一页。
  4. 卖家点击商品卡片 → `<a-modal>` 提示「预览模式，不可跳转商品详情」。
- **分支流程**：
  - 店铺暂停态：商品列表展示但标注「店铺暂停，商品暂不可购买」。
  - 店铺关闭态：提示「店铺已关闭，前台不可访问」，不展示内容。
  - 无在售商品：商品区显示 `<EmptyState title="暂无在售商品" />`。
- **跨页面流转**：无跳转（预览模式）；顶部提供「返回编辑」按钮回到店铺资料页。
- **状态机可视化**：无状态机；展示店铺当前状态对应的前台效果。

## 5. 组件清单
- **基础组件**：`<a-card>`、`<a-avatar>`、`<a-rate>`、`<a-list>`、`<a-alert>`、`<a-modal>`、`<a-empty>`、`<a-breadcrumb>`、`<a-skeleton>`。
- **业务组件**：`StatusTag`（见 shared/components.md §1，type="shop"）— 店铺状态标注；`EmptyState`（见 shared/components.md §5）— 无商品占位。
- **图表组件**：无。
- **图标使用**：`ShopOutlined`（页面图标）、`HeartOutlined`（收藏）、`StarOutlined`（评分）、`CustomerServiceOutlined`（客服）。
- **空状态**：无在售商品时 `<EmptyState title="暂无在售商品" description="发布商品并通过审核后将在前台展示" />`。

## 6. 视觉规范
- **主色应用**：关注按钮、商品价格使用主色 `#1677FF`；预览提示条 info 蓝色边框。
- **状态色**：店铺状态 `StatusTag` —— 营业中绿、暂停黄、关闭灰；暂停态提示条 warning 黄。
- **间距**：店铺头部内边距 `24px`，信息栏间距 `16px`，商品卡片间距 `16px`，商品卡片内边距 `12px`。
- **字体**：店铺名称 `24px` semibold，描述 `14px` normal，商品标题 `14px` medium，价格 `16px` semibold 红色 `#FF4D4F`。
- **图标尺寸**：Logo `128px`，评分星星 `20px`，关注/收藏图标 `20px`。

## 7. 异常处理与边界
- **加载态**：进入页面 `<a-skeleton>` 模拟店铺头部与商品瀑布流布局。
- **空数据**：店铺无在售商品显示 `<EmptyState>`；店铺关闭态不展示内容仅提示。
- **错误态**：网络错误 `message.error('网络异常')`；403 `message.error('无权限访问')`；404（店铺不存在）提示「未找到店铺」。
- **权限控制**：仅店铺所属卖家可预览自己店铺；预览数据与买家看到的公开信息一致（客服电话脱敏展示）。
- **并发与乐观锁**：预览为只读操作，无并发冲突。
- **危险操作确认**：预览页无危险操作；商品卡片点击仅提示不可跳转，无副作用。
