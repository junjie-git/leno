# 物流轨迹 - 商家管理后台

## 1. 页面定位
- **所属端**：商家管理后台
- **所属模块**：05-order-fulfillment（订单履约）
- **页面类型**：详情页（只读）
- **目标用户**：卖家（Seller）
- **核心目标**：卖家查看已发货订单的物流轨迹详情，掌握包裹运输进度，便于回复买家咨询。
- **访问入口**：订单列表「物流轨迹」按钮；URL `/orders/:id/trace`。
- **实现状态**：✅ 已实现

## 2. 页面布局与信息架构
- **整体布局**：顶部面包屑 + 订单摘要条 + 物流信息卡 + 轨迹时间线 + 底部返回。
- **关键区域**：
  - 区域 A（面包屑）：首页 / 订单履约 / 全部订单 / 物流轨迹。
  - 区域 B（订单摘要条）：`<a-descriptions>` 展示订单编号、订单状态 StatusTag、收货人（脱敏）、收货地址（脱敏）、下单时间、发货时间。
  - 区域 C（物流信息卡 `<a-card>`）：展示物流公司名称、物流单号（可复制）、当前状态（运输中/已签收/异常）、最后更新时间。若物流公司不支持轨迹查询，展示提示条。

- **首屏内容**：订单摘要 + 物流信息卡 + 轨迹时间线前 5 条。

## 3. 数据模型与 API 对接
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| GET | `/api/orders/{id}/logistics-trace` | 查询订单物流轨迹 | Seller |

- **请求参数**：路径参数 `id` 为订单 ID（Guid）。无额外查询参数。
- **响应字段**：`LogisticsTrackingDto` 含 `logisticsCompanyCode`、`logisticsCompanyName`、`logisticsNo`、`currentStatus`（运输中/已签收/异常/不支持查询）、`lastUpdatedAt?`、`tracks[]`（每条含 `time`、`location`、`description`）、`isCached`（bool，表示是否来自缓存）、`warning?`（缓存或降级时的警告信息）。
- **数据加载策略**：进入页面调用 `GET /api/orders/{id}/logistics-trace` 一次性加载轨迹；不自动轮询（卖家主动刷新查看）。
- **缓存策略**：后端在物流公司不支持轨迹查询或接口异常时返回缓存数据并带 `warning` 标识；前端展示警告条。

## 4. 交互流程
- **主流程**：
  1. 卖家从订单列表点击「物流轨迹」→ 跳转 `/orders/:id/trace` → 调用 `GET /api/orders/{id}/logistics-trace` → 渲染摘要、信息卡、时间线。
  2. 卖家点击「复制」物流单号 → 写入剪贴板 → `message.success('单号已复制')`。
  3. 卖家点击「刷新」→ 重新调用轨迹端点 → 更新时间线。
  4. 卖家点击「返回订单列表」→ 跳转 `/orders`。
- **分支流程**：
  - 物流公司不支持轨迹查询：信息卡展示 `<a-alert type="warning">` 提示「该公司不支持轨迹查询，如需了解进度请联系物流公司客服」。
  - 轨迹数据来自缓存（`isCached=true`）：顶部展示 `<a-alert type="info">` 提示「当前展示为缓存数据，可能存在延迟」。
  - 无轨迹数据：时间线区域展示 `<EmptyState>`。
- **跨页面流转**：返回订单列表；订单编号点击可跳回订单列表对应行。
- **状态机可视化**：物流状态：运输中 → 已签收（终态）；运输中 → 异常（需人工介入）。

## 5. 组件清单
- **基础组件**：`<a-descriptions>`、`<a-card>`、`<a-timeline>`、`<a-timeline-item>`、`<a-button>`、`<a-alert>`、`<a-tag>`、`<a-tooltip>`。
- **业务组件**：`StatusTag`（见 shared/components.md §1，type="order"）— 订单状态展示；`EmptyState`（见 shared/components.md §5）— 无轨迹占位。

- **空状态**：`<EmptyState title="暂无物流轨迹" description="尚未获取到物流轨迹信息，请稍后刷新" />`。

## 6. 视觉规范
- **主色应用**：时间线最新节点使用主色 `#1677FF`；「复制」链接使用主色；刷新按钮主色。
- **状态色**：运输中蓝 `#1677FF`、已签收绿 `#52C41A`、异常红 `#FF4D4F`；缓存提示 info 蓝；不支持查询 warning 黄。
- **间距**：摘要条与信息卡间距 `16px`，信息卡与时间线间距 `24px`，时间线节点间距 `16px`，时间线左侧时间线宽度 `120px`。
- **字体**：页面标题 `20px` medium，摘要 `14px` normal，物流单号 `14px` semibold（等宽字体），时间线时间 `12px` `#8C8C8C`，时间线描述 `14px` normal。
- **图标尺寸**：复制图标 `16px`，地点图标 `16px`，时间线节点 `default` 尺寸。

## 7. 异常处理与边界
- **加载态**：进入页面 `<a-skeleton>` 模拟信息卡与时间线；刷新时按钮 loading。
- **空数据**：无轨迹数据时时间线区域展示 `<EmptyState>`。
- **错误态**：网络错误 `message.error('网络异常')`；403 `message.error('无权限访问')`；404（订单不存在）`message.error('订单不存在')` 并跳回列表；轨迹查询失败展示后端 `warning` 信息。
- **权限控制**：需卖家登录态；后端校验订单 SellerId 与当前卖家一致，非本店订单返回 403。
- **并发与乐观锁**：只读页面，无并发冲突。
- **危险操作确认**：无危险操作（只读页面）。
