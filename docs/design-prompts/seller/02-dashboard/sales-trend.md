# 销售趋势 - 商家管理后台

## 1. 页面定位
- **所属端**：商家管理后台
- **所属模块**：02-dashboard（工作台）
- **页面类型**：看板页
- **目标用户**：卖家（Seller）
- **核心目标**：卖家按自定义时间范围分析销售额、订单数、客单价等趋势指标，辅助经营决策。
- **访问入口**：Sider「工作台 → 销售趋势」；工作台概览趋势图标题点击。
- **实现状态**：✅ 已实现

## 2. 页面布局与信息架构
- **整体布局**：顶部面包屑 + 顶部筛选栏（时间范围 + 指标切换）+ 4 个指标汇总卡片 + 主趋势折线图 + 副指标明细表格。
- **关键区域**：
  - 区域 A（面包屑）：首页 / 工作台 / 销售趋势。
  - 区域 B（筛选栏）：`DateTimeRangePicker` 时间范围（默认近 30 天，预设今日/昨日/近 7 天/近 30 天/本月）+ `<a-segmented>` 指标切换（销售额/订单数/客单价）。
  - 区域 C（指标汇总卡片区）：4 个 `DashboardCard` —— 总销售额、总订单数、平均客单价、已完成订单数，每卡含环比趋势。
  - 区域 D（主趋势折线图）：`ChartLine` 展示所选指标按日序列，X 轴日期，Y 轴指标值，支持鼠标悬停显示具体数值。
  - 区域 E（副指标明细表格）：`<a-table>` 按日展示日期、订单数、销售额、客单价、退款数，支持排序。
- **响应式断点**：≥1200px 全展开；992-1199px 指标卡片 2×2 + 表格横向滚动；<992px 不支持。
- **首屏内容**：筛选栏 + 4 个指标卡片 + 趋势图标题。

## 3. 数据模型与 API 对接
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| GET | `/api/seller/sales-trend?from=&to=` | 销售趋势（按日序列） | Seller |
| GET | `/api/seller/metrics?from=&to=` | 运营指标明细（按日） | Seller |

- **请求参数**：两端点均接收 `from`/`to`（DateOnly）。`sales-trend` 返回销售额与订单数；`metrics` 返回更丰富的指标（订单数、销售额、平均评分、评分数、退款数）。
- **响应字段**：`SalesTrendDto[]` 含 `date`、`orderCount`、`salesAmount`；`ShopMetricsDto[]` 含 `date`、`orderCount`、`salesAmount`、`salesCurrency`、`avgRating`、`ratingCount`、`refundCount`。前端用 `metrics` 数据填充明细表格与汇总卡片，用 `sales-trend` 填充折线图。
- **数据加载策略**：进入页面并行调用 sales-trend 与 metrics（默认近 30 天）；时间范围变更重新调用。
- **缓存策略**：缓存 5 分钟（键 `seller:sales-trend:{sellerId}:{from}:{to}` 与 `seller:metrics:{sellerId}:{from}:{to}`）。

## 4. 交互流程
- **主流程**：
  1. 卖家进入页面 → 并行调用 sales-trend 与 metrics（近 30 天）→ 渲染汇总卡片、趋势图、明细表格。
  2. 卖家切换时间范围预设（如「近 7 天」）→ 重新调用两端点 → 刷新所有区域。
  3. 卖家自定义时间范围 → 防抖 300ms 后重新调用。
  4. 卖家切换指标（销售额/订单数/客单价）→ 趋势图 Y 轴切换，明细表格高亮对应列。
  5. 卖家点击明细表格列头 → 按该列排序。
- **分支流程**：
  - 时间范围超过 90 天：提示「最多支持 90 天范围」，截断为 90 天。
  - 无数据日期：趋势图断点显示 0，明细表格显示 0 值行。
- **跨页面流转**：点击明细表格行可跳转当日订单列表（携带日期过滤）。
- **状态机可视化**：无状态机。

## 5. 组件清单
- **基础组件**：`<a-breadcrumb>`、`<a-card>`、`<a-table>`、`<a-segmented>`、`<a-skeleton>`、`<a-spin>`。
- **业务组件**：`DateTimeRangePicker`（见 shared/components.md §4）— 时间范围选择；`DashboardCard`（见 shared/components.md §8）— 4 个汇总卡片；`ChartLine`（见 shared/components.md §7.1）— 主趋势折线图；`EmptyState`（见 shared/components.md §5）— 无数据占位。
- **图表组件**：`ChartLine` —— 单 Y 轴动态切换（销售额元 / 订单数笔 / 客单价元），smooth 曲线，主色 `#1677FF`，悬停 tooltip。
- **图标使用**：`LineChartOutlined`（页面图标）、`RiseOutlined`/`FallOutlined`（趋势）、`CalendarOutlined`（时间）。
- **空状态**：无数据时趋势图与表格均显示 `<EmptyState title="暂无数据" description="所选时间范围内无销售记录" />`。

## 6. 视觉规范
- **主色应用**：趋势图主线、指标切换激活态、表格当前排序列头使用主色 `#1677FF`。
- **状态色**：趋势上升绿 `#52C41A`，下降红 `#FF4D4F`；退款数列用 warning 黄 `#FAAD14` 文字。
- **间距**：筛选栏与卡片间距 `24px`，卡片间距 `16px`，趋势图高度 `300px`，表格行高 `48px`。
- **字体**：页面标题 `20px` medium，汇总卡片数值 `24px` semibold，趋势图轴标签 `12px`，表格 `14px` normal。
- **图标尺寸**：汇总卡片图标 `24px`，趋势箭头 `12px`，表格排序图标 `16px`。

## 7. 异常处理与边界
- **加载态**：汇总卡片 `<a-skeleton>`，趋势图 `<a-spin>` 包裹，表格 `<a-skeleton>`。
- **空数据**：`<EmptyState>` 占位，提示「所选时间范围内无销售记录」。
- **错误态**：网络错误 `message.error('网络异常')`；403 `message.error('无权限访问')`；时间范围非法（from > to）前端校验拦截。
- **权限控制**：需卖家登录态，仅可见本店数据。
- **并发与乐观锁**：只读分析页，无并发冲突。
- **危险操作确认**：无危险操作。
