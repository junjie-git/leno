# 物流公司查询 - 商家管理后台

## 1. 页面定位
- **所属端**：商家管理后台
- **所属模块**：04-logistics（物流管理）
- **页面类型**：列表页（只读）
- **目标用户**：卖家（Seller）
- **核心目标**：卖家查看平台可用物流公司清单（名称、编码、客服电话、是否支持轨迹查询），发货时从中选择。
- **访问入口**：Sider「物流管理 → 物流公司查询」；待发货订单发货弹窗内联选择。
- **实现状态**：➕ 补充功能

- **整体布局**：顶部面包屑 + 提示条 + 筛选栏 + 物流公司表格 + 底部分页。
- **关键区域**：

  - 区域 B（提示条）：`<a-alert type="info" banner>` 提示「以下为平台运营维护的物流公司，发货时请选择启用状态的公司」。

## 3. 数据模型与 API 对接
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| GET | `/api/admin/logistics-companies` | 分页查询物流公司（运营维护，卖家需补充只读访问权限） | Seller（补充） |

- **请求参数**：`GET /api/admin/logistics-companies?page=1&pageSize=20`。当前后端端点鉴权为 Operator/Admin，卖家角色无法直接访问。**补充功能说明**：需后端新增卖家只读查询端点（如 `GET /api/seller/logistics-companies`），仅返回启用态公司清单供卖家发货选择，不开放增删改权限。
- **响应字段**：`LogisticsCompanyDto[]`，每个含 `id`、`name`、`code`、`servicePhone`、`supportTracking`（bool）、`status`（Enabled/Disabled）。前端按 `status` 与 `supportTracking` 渲染标签。
- **数据加载策略**：进入页面加载第一页（20 条）；筛选条件变更重新加载；分页切换加载对应页。
- **缓存策略**：物流公司主数据低频变更，前端缓存 10 分钟（键 `seller:logistics-companies`），降低请求频率。

## 4. 交互流程
- **主流程**：
  1. 卖家进入页面 → 调用物流公司查询端点 → 渲染提示条与表格。
  2. 卖家输入关键词 → 防抖 300ms 后重新查询。
  3. 卖家选择状态/轨迹筛选 → 重新查询。
  4. 卖家点击「复制编码」→ 将公司编码写入剪贴板 → `message.success('编码已复制')`，便于粘贴到发货弹窗的 `LogisticsCompanyCode` 字段。
- **分支流程**：
  - 公司为停用态：操作列不显示「复制编码」，灰色提示「已停用」。
  - 不支持轨迹查询：轨迹列展示灰色「不支持」标签，发货后物流轨迹页将提示「该公司不支持轨迹查询」。
- **跨页面流转**：复制编码后可手动跳转待发货订单页；发货弹窗内联选择时直接填入。
- **状态机可视化**：物流公司状态：启用（可发货选择）/ 停用（不可选，已发货订单展示不受影响）。

## 5. 组件清单
- **基础组件**：`<a-alert>`、`<a-input-search>`、`<a-select>`、`<a-table>`、`<a-pagination>`、`<a-tag>`、`<a-tooltip>`。
- **业务组件**：`StatusTag`（见 shared/components.md §1，type="shop"）— 公司启停状态；`DataTable`（见 shared/components.md §6）— 物流公司表格；`EmptyState`（见 shared/components.md §5）— 无数据占位。
- **图表组件**：无。
- **图标使用**：`CopyOutlined`（复制编码）、`CheckCircleOutlined`（支持轨迹）、`CloseCircleOutlined`（不支持轨迹）。
- **空状态**：`<EmptyState title="暂无物流公司" description="平台尚未配置物流公司，请联系运营" />`。

## 6. 视觉规范
- **主色应用**：「复制编码」链接使用主色 `#1677FF`；支持轨迹标签 info 蓝。
- **状态色**：启用绿 `#52C41A`、停用灰 `#8C8C8C`；支持轨迹绿 `#52C41A` + CheckCircleOutlined、不支持灰 `#8C8C8C` + CloseCircleOutlined。
- **间距**：提示条与筛选栏间距 `12px`，筛选栏与表格间距 `16px`，表格行高 `48px`。
- **字体**：页面标题 `20px` medium，提示条 `14px` normal，表格 `14px` normal，公司编码 `14px` semibold（等宽字体优先）。
- **图标尺寸**：轨迹状态图标 `16px`，复制图标 `16px`。

## 7. 异常处理与边界
- **加载态**：进入页面 `<a-skeleton>` 模拟表格 5 行。
- **空数据**：`<EmptyState>` 提示联系运营。
- **错误态**：网络错误 `message.error('网络异常')`；403 `message.error('无权限访问，物流公司由运营维护')`；查询失败展示后端原因。
- **权限控制**：需卖家登录态；当前后端端点仅 Operator/Admin 可访问，**补充功能**需后端开放卖家只读权限或新增卖家专用端点。
- **并发与乐观锁**：只读页面，无并发冲突。
- **危险操作确认**：无危险操作（只读页面）。

## 8. 验收要点
- [ ] 提示条正确说明物流公司由运营维护
- [ ] 表格展示公司名称、编码、客服电话、轨迹支持、状态
- [ ] 关键词搜索防抖 300ms 后触发查询
- [ ] 「复制编码」按钮将编码写入剪贴板并提示成功
- [ ] 停用态公司不显示复制按钮

- **可访问性**：表格有 `aria-label="物流公司列表"`；复制按钮有 `aria-label`；轨迹状态有 `aria-label`；对比度满足 WCAG AA。

> **补充功能说明**：当前后端 `LogisticsCompaniesController` 端点鉴权为 Operator/Admin，卖家角色无法直接访问。本页面为补充功能，需后端新增 `GET /api/seller/logistics-companies` 只读端点（仅返回启用态公司），或在现有端点开放 Seller 角色只读权限。卖家端仅查询不增删改，物流公司主数据由运营在运营管理后台维护。
