# 价格历史 - 商家管理后台

## 1. 页面定位
- **所属端**：商家管理后台
- **所属模块**：03-product-management（商品管理）
- **页面类型**：详情页（只读看板）
- **目标用户**：卖家（Seller）
- **核心目标**：卖家查看某商品各 SKU 的价格变更历史记录，掌握调价轨迹与变更原因，辅助定价决策。
- **访问入口**：SKU 管理页「调价记录」链接；商品编辑页「价格历史」；URL `/products/:id/price-history`。
- **实现状态**：✅ 已实现

## 2. 页面布局与信息架构
- **整体布局**：顶部面包屑 + 商品摘要条 + SKU 筛选 + 价格趋势折线图 + 价格变更记录表格。
- **关键区域**：
  - 区域 A（面包屑）：首页 / 商品管理 / 商品列表 / 价格历史。
  - 区域 B（商品摘要条）：`<a-descriptions>` 展示商品标题、状态 StatusTag、当前价格区间。
  - 区域 C（SKU 筛选）：`<a-select>` 展示该商品全部 SKU（编码 + 规格组合），默认「全部 SKU」。
  - 区域 D（价格趋势图 `<ChartLine>`）：横轴为变更时间，纵轴为价格（元），多系列按 SKU 区分，hover 显示旧价格、新价格、变更人、变更原因。
  - 区域 E（变更记录表格 `<a-table>`）：列含变更时间、SKU 编码、规格组合、旧价格、新价格、变动幅度（涨/跌百分比）、变更人、变更原因。按时间倒序，>100 行虚拟滚动。
- **响应式断点**：≥1200px 图表与表格全宽；992-1199px 表格横向滚动；<992px 不支持。
- **首屏内容**：商品摘要 + 趋势图 + 变更记录前 20 条。

## 3. 数据模型与 API 对接
- **主要 API**：

| 方法 | 端点 | 用途 | 鉴权 |
|-|-|-|-|
| GET | `/api/products/{id}/price-history` | 查询商品价格变更历史 | Seller |
| GET | `/api/products/{id}` | 查询商品详情（含 SKU 信息回填筛选） | Seller |

- **请求参数**：`GET /api/products/{id}/price-history?skuId={skuId?}`，`skuId` 可空表示查询全部 SKU。无需分页参数（历史记录通常全量返回，前端按时间倒序展示）。
- **响应字段**：`PriceChangeRecordDto[]`，每条含 `skuId`、`oldPrice`、`newPrice`、`currency`、`changedAt`（UTC）、`changedBy`（操作人姓名/ID）、`reason?`。前端按 `skuId` 关联 `ProductDto.skus[]` 得出 SKU 编码与规格组合，计算变动幅度 `((newPrice - oldPrice) / oldPrice * 100)%`。
- **数据加载策略**：进入页面并行调用 `GET /api/products/{id}`（获取 SKU 元数据）与 `GET /api/products/{id}/price-history`（获取变更记录）；SKU 筛选变更时前端过滤本地数据，无需重新请求。
- **缓存策略**：不缓存，保证调价记录时效性。

## 4. 交互流程
- **主流程**：
  1. 卖家进入页面 → 并行拉取商品详情与价格历史 → 渲染摘要条、趋势图、变更记录表格。
  2. 卖家选择特定 SKU → 趋势图与表格按 `skuId` 前端过滤 → 切换「全部 SKU」恢复全量。
  3. 卖家 hover 趋势图节点 → Tooltip 展示该次变更详情（旧价、新价、变更人、原因、时间）。
- **分支流程**：
  - 无价格变更记录：趋势图显示空态，表格展示 `<EmptyState>`。
  - 单个 SKU 仅一次变更：趋势图展示两点连线。
- **跨页面流转**：面包屑返回商品列表；SKU 编码点击跳转 SKU 管理页。
- **状态机可视化**：无状态机（只读历史记录）。

## 5. 组件清单
- **基础组件**：`<a-descriptions>`、`<a-select>`、`<a-table>`、`<a-tag>`、`<a-tooltip>`。
- **业务组件**：`StatusTag`（见 shared/components.md §1，type="product"）— 商品状态展示；`ChartLine`（见 shared/components.md §7.1）— 价格趋势折线图；`DataTable`（见 shared/components.md §6）— 变更记录表格；`EmptyState`（见 shared/components.md §5）— 无记录占位。
- **图表组件**：`ChartLine` — 多系列折线图，seriesField 为 SKU 编码，xField 为 `changedAt`，yField 为 `newPrice`。
- **图标使用**：`RiseOutlined`（涨价）、`FallOutlined`（降价）、`HistoryOutlined`（历史）。
- **空状态**：`<EmptyState title="暂无价格变更记录" description="该商品尚未发生价格调整" />`。

## 6. 视觉规范
- **主色应用**：趋势图主线使用主色 `#1677FF`；多 SKU 系列使用设计令牌色彩循环（主色/成功/警告/中性）。
- **状态色**：涨价幅度文字红 `#FF4D4F` + `RiseOutlined`；降价幅度文字绿 `#52C41A` + `FallOutlined`；无变更灰色 `#8C8C8C`。
- **间距**：摘要条与筛选栏间距 `16px`，趋势图高度 `300px`，趋势图与表格间距 `24px`，表格行高 `48px`。
- **字体**：页面标题 `20px` medium，摘要 `14px` normal，趋势图坐标轴 `12px` `#8C8C8C`，表格 `14px` normal，价格 `14px` semibold。
- **图标尺寸**：涨跌图标 `16px`，历史图标 `20px`。

## 7. 异常处理与边界
- **加载态**：进入页面 `<a-skeleton>` 模拟趋势图与表格；趋势图加载时 `<a-spin>`。
- **空数据**：无变更记录时趋势图显示 `<EmptyState>`，表格显示 `<EmptyState>`。
- **错误态**：网络错误 `message.error('网络异常')`；403 `message.error('无权限访问')`；404（商品不存在）`message.error('商品不存在')` 并跳回列表。
- **权限控制**：需卖家登录态；后端校验商品归属，非本店商品返回 403。
- **并发与乐观锁**：只读页面，无并发冲突。
- **危险操作确认**：无危险操作（只读页面）。
