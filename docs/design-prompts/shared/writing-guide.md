# 文案与微交互风格指南

**文档版本**：V1.0
**适用范围**：4 端所有页面提示词
**最后更新**：2026-07-26

本文件定义文案风格、微交互、空状态、加载态、危险操作的统一约定。所有 subagent 在页面提示词中描述交互行为时，必须引用本文件的规则。

---

## 1. 文案风格

### 1.1 基本原则

- **简洁中性**：避免口语化、避免冗余修饰
- **动词开头**：操作类文案以动词开头
- **用户视角**：从用户角度描述，而非系统角度
- **一致性**：相同操作使用相同动词，避免同义词混用

### 1.2 正反例

| 场景 | ❌ 反例 | ✅ 正例 |
|-|-|-|
| 按钮文案 | 点击这里提交审核 | 提交审核 |
| 按钮文案 | 确认删除吗？ | 删除 |
| 提示文案 | 系统已经成功为您创建了订单 | 订单创建成功 |
| 提示文案 | 抱歉，您没有权限执行此操作 | 无权限访问 |
| 空状态 | 暂无数据，请添加 | 暂无商品，点击「新增商品」开始添加 |
| 表单标签 | 请输入您的用户名 | 用户名 |

### 1.3 按钮动词清单

统一使用以下动词，不得使用同义词：

| 操作 | 统一动词 | 禁用同义词 |
|-|-|-|
| 提交表单 | 提交 | 确认、确定、发送 |
| 保存数据 | 保存 | 存储、更新、修改 |
| 确认对话框 | 确认 | 确定、OK、好的 |
| 取消操作 | 取消 | 返回、放弃、关闭 |
| 删除数据 | 删除 | 移除、清除、drop |
| 编辑数据 | 编辑 | 修改、更改、update |
| 查看详情 | 查看 | 详情、浏览、查看详情 |
| 导出数据 | 导出 | 下载、输出 |
| 新增数据 | 新增 | 添加、创建、新增数据 |
| 审核通过 | 通过 | 同意、批准、approve |
| 审核驳回 | 驳回 | 拒绝、不同意、reject |
| 启用 | 启用 | 开启、打开、enable |
| 停用 | 停用 | 关闭、禁用、disable |

## 2. 微交互

### 2.1 表单提交

- **防抖**：输入框 300ms 防抖，避免频繁校验
- **重复点击拦截**：提交按钮点击后立即 disabled + loading，直至响应返回
- **校验时机**：失焦时校验单字段，提交时校验全表单
- **成功反馈**：`message.success('操作成功')` 显示 1.5s 后自动关闭
- **失败反馈**：`message.error(错误信息)` 显示 3s，错误信息来自后端 response.data.message

### 2.2 列表加载

- **首屏骨架屏**：进入列表页首屏显示 Skeleton（3-5 行占位）
- **分页加载**：底部分页器点击后显示 Spin，数据返回后替换
- **无限滚动**（用户 APP）：`van-list` 的 `loading` 状态，底部显示加载中
- **刷新**：下拉刷新（用户 APP `van-pull-refresh`）或刷新按钮（三端后台）

### 2.3 操作反馈

| 操作类型 | 反馈方式 | 持续时间 |
|-|-|-|
| 成功 | `message.success` | 1.5s |
| 失败 | `message.error` | 3s |
| 警告 | `message.warning` | 2s |
| 信息 | `message.info` | 1.5s |
| 危险操作确认 | `Modal.confirm` / `showConfirmDialog` | 用户确认前不消失 |
| 长任务进度 | `Spin.useSpin()` / `showLoadingToast` | 任务完成自动关闭 |

## 3. 空状态

### 3.1 空状态组件

- **三端后台**：`<a-empty description="暂无{数据}" />` + CTA 按钮
- **用户 APP**：`<van-empty description="暂无{数据}" />` + CTA 按钮

### 3.2 CTA 文案规范

| 场景 | 空状态描述 | CTA 文案 |
|-|-|-|
| 商品列表 | 暂无商品 | 新增商品 |
| 订单列表 | 暂无订单 | 去逛逛（用户 APP）/ — （后台） |
| 优惠券 | 暂无优惠券 | 去领取 |
| 通知 | 暂无通知 | — |
| 搜索结果 | 未找到相关商品 | 清空筛选条件 |
| 购物车 | 购物车空空如也 | 去购物 |

### 3.3 空状态视觉

- 图标使用 `@ant-design/icons-vue` 或 Vant 内置的 Empty 插画
- 文字描述居中，14px，颜色 `#8C8C8C`
- CTA 按钮使用主色 `#1677FF`，圆角 `6px`

## 4. 加载态

### 4.1 加载态使用场景

| 场景 | 三端后台 | 用户 APP |
|-|-|-|
| 首屏页面加载 | `<a-skeleton>` 骨架屏（模拟最终布局） | `<van-skeleton>` 骨架屏 |
| 卡片/区块加载 | `<a-skeleton :active="true" />` | `<van-skeleton>` |
| 表格加载 | `<a-spin>`（包裹表格） | — |
| 按钮提交 | 按钮 `loading` prop | 按钮 `loading` prop |
| 局部刷新 | `<a-spin>` | `showLoadingToast` |
| 全屏加载（长任务） | `Spin.useSpin()` | `showLoadingToast({ forbidClick: true })` |

### 4.2 骨架屏规范

- **首屏**：必须使用骨架屏，不得显示空白页面
- **形状**：模拟最终布局的卡片/列表/表格形状
- **动画**：`active` 动画效果（波浪效果）
- **持续时间**：< 300ms 不显示加载态（避免闪烁）；> 300ms 显示

## 5. 危险操作确认

### 5.1 必须二次确认的操作

以下操作必须使用 `Modal.confirm`（三端后台）或 `showConfirmDialog`（用户 APP）二次确认：

- **删除**：删除商品、删除角色、删除字典等
- **暂停**：暂停店铺、暂停会员等级、暂停定时任务
- **关闭**：关闭促销活动、关闭秒杀活动、关闭店铺
- **驳回**：驳回入驻申请、驳回商品审核、驳回售后
- **强制取消**：运营强制取消订单
- **丢弃**：丢弃死信消息
- **重投**：重投死信消息
- **封禁**：封禁用户、封禁店铺
- **下架**：下架商品

### 5.2 确认对话框规范

**三端后台**（Ant Design Vue）：

```typescript
Modal.confirm({
  title: '确认{操作}',
  content: '{操作}后将{后果说明}，此操作{是否可逆}。',
  okText: '确认{操作}',
  okType: 'danger',  // 红色危险按钮
  cancelText: '取消',
  onOk: () => { /* 执行操作 */ }
});
```

**用户 APP**（Vant）：

```typescript
showConfirmDialog({
  title: '确认{操作}',
  message: '{操作}后将{后果说明}，此操作{是否可逆}。',
  confirmButtonText: '确认{操作}',
  confirmButtonColor: '#FF4D4F',  // 红色危险按钮
  cancelButtonText: '取消'
}).then(() => { /* 执行操作 */ });
```

### 5.3 确认文案规范

- **标题**：「确认{操作}」，如「确认删除」「确认驳回」
- **内容**：必须说明后果与是否可逆，如「删除后将无法恢复，关联的{N}条数据将一并删除」
- **确认按钮**：使用 `danger` 类型（红色），文案为「确认{操作}」
- **取消按钮**：默认样式，文案为「取消」

## 6. 表单校验

### 6.1 校验规则

- **必填**：`required: true, message: '请输入{字段名}'`
- **长度**：`min: N, max: M, message: '{字段名}长度需在 {N}-{M} 字符之间'`
- **模式**：`pattern: /正则/, message: '{字段名}格式不正确'`
- **自定义**：`validator: (rule, value) => Promise<void>`

### 6.2 校验时机

- **失焦校验**：单个字段失焦时校验
- **提交校验**：提交时全表单校验，第一个错误字段滚动定位
- **实时清除**：字段有值时清除该字段错误

### 6.3 错误展示

- **位置**：字段下方，红色文字 `#FF4D4F`，12px
- **图标**：错误前缀 `<a-form-item validate-status="error">` 自动展示错误图标
- **汇总**：表单顶部不汇总错误，逐字段展示

## 7. 通知与消息中心

### 7.1 通知类型

| 类型 | 图标 | 颜色 | 场景 |
|-|-|-|-|
| 成功 | CheckCircle | `#52C41A` | 操作成功 |
| 警告 | ExclamationCircle | `#FAAD14` | 临期提醒、库存预警 |
| 错误 | CloseCircle | `#FF4D4F` | 操作失败、系统异常 |
| 信息 | InfoCircle | `#1677FF` | 一般通知 |

### 7.2 通知中心

- **位置**：三端后台 Header 右上角铃铛图标；用户 APP「我的」页顶部入口
- **未读数**：`<a-badge :count="N" />` 或 `<van-badge :content="N" />`
- **列表**：按时间倒序，未读项左侧有蓝点标记
- **标记已读**：点击单条标记已读；「全部已读」按钮批量标记

## 8. 响应式与适配

### 8.1 三端后台

- **断点**：≥1200px 全展开；992-1199px Sider 折叠；<992px 不支持
- **表格**：列数 > 8 时启用横向滚动 `<a-table :scroll="{ x: 1200 }" />`
- **表单**：垂直表单为主，label 位置 `top`

### 8.2 用户 APP

- **基准**：375px 宽度设计
- **适配**：使用 `rem` 或 `vw` 单位，根字号 16px
- **安全区**：底部 Tabbar 适配 `safe-area-inset-bottom`
- **图片**：使用 `van-image` 的 `lazy-load` 懒加载
