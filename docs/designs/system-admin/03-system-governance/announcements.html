限时秒杀活动上线预告

亲爱的买家用户：

我们将于 2026 年 7 月 28 日 20:00 正式上线限时秒杀功能，届时可在 APP 首页秒杀专区参与抢购。

  • 秒杀场次：每日 10:00 / 14:00 / 20:00 三场
  • 每个用户每场限购 1 件，下单后 15 分钟内未支付自动取消
  • 秒杀商品不参与优惠券叠加，支持七天无理由退货

温馨提示：秒杀库存有限，抢完即止。请提前登录并确保收货地址完整。

如有疑问请联系客服。祝您购物愉快！

置顶
确认发布公告
发布后公告将对所选范围（买家 APP）立即生效，买家 APP 将展示该公告。
撤回可恢复，已读记录保留。发布将触发集成事件通知各端刷新公告缓存。
仅 Admin 角色可发布公告。发布后不可编辑，需撤回后重新编辑发布。
确认撤回公告
撤回后公告将立即从所有端下线，已读记录保留。
可重新编辑后再次发布。撤回操作将触发集成事件通知各端清除公告缓存。
仅已发布态的公告可撤回，草稿与已撤回态无需此操作。
