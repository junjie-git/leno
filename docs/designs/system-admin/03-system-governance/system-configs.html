新建系统配置
确认停用配置

即将停用配置 payment.timeout。

停用后使用该配置的功能将回退到默认值，可能影响线上行为（支付超时将按代码默认值 15 分钟处理）。可随时启用恢复。
查看明文 - 二次鉴权

查看敏感配置 notify.smtp.password 的明文，需重新输入管理员密码进行二次鉴权。本次操作将记录审计日志。

仅 Admin 角色可查看明文，Operator 无权限
