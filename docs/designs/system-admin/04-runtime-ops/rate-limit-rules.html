编辑限流规则
一个 API 路径仅允许配置一条规则，重复配置后端返回 409
滑动窗口精度最高；令牌桶允许突发；固定窗口实现简单但有边界突刺
确认停用限流规则
即将停用规则 POST /api/orders（Order · 1000/60s）。
停用后该 API 将不再受限流保护，可能在高并发下被击穿。可随时启用恢复。
