处置建议
支付服务错误率飙升处置流程：
1) 立即查看支付渠道连通性，确认支付宝/微信支付网关是否可达；
2) 检查支付证书是否过期（重点关注 SSL handshake 错误）；
3) 确认出口 IP 是否被支付渠道风控；
4) 必要时切换至备用支付渠道，通知业务方暂停大额支付下单；
5) 查看 Prometheus 指标 payment_error_rate 与 payment_channel_status 趋势；
6) 处置完成后在此添加注释，并确认告警恢复。
