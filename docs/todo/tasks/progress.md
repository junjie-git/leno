### 3.2 关键依赖链

| 依赖链                             | 说明                                  | 影响                     |
| ---------------------------------- | ------------------------------------- | ------------------------ |
| 共享内核 → 全部模块                | 测试基础设施、对象存储、OpenTelemetry | 阻塞所有模块的测试与集成 |
| BC1 用户域 → BC3 购物车/BC4 订单   | 用户身份认证与地址快照                | 阻塞购物车与订单功能     |

| BC9 店铺域 → BC2 商品域/BC4 订单域 | 店铺状态事件联动                      | 阻塞商品上下架与订单履约 |
| BC4 订单域 → BC7 积分域            | 售后期结束事件驱动积分发放            | 阻塞积分体系             |
| BC4 订单域 → BC5 促销域            | 支付成功事件驱动核销                  | 阻塞优惠券核销           |
| BC4 订单域 → BC6 支付域            | 发起支付请求                          | 阻塞支付流程             |
| BC6 支付域 → BC4 订单域            | 支付结果回调                          | 阻塞订单状态流转         |
| BC8 售后域 → BC6 支付域            | 退款请求                              | 阻塞退款流程             |

| BC11 管理域 → 全部模块             | 统计看板、死信管理、索引重建          | 阻塞运维能力             |

### 6.2 优先级定义

| 优先级 | 含义                             | 建议处理时间 |
| ------ | -------------------------------- | ------------ |
| P0     | 关键：阻塞核心业务流程或安全合规 | 当前迭代     |
| P1     | 重要：影响主要功能或用户体验     | 下个迭代     |
| P2     | 一般：优化体验或运维便利         | 排期处理     |

### 6.3 子任务粒度标准

每个子任务应满足以下标准：

- 可在 1-2 个工作日内完成
- 具有明确的验收标准（可测试）
- 无外部依赖或依赖已就绪
- 产出可独立提交（单一 commit）
